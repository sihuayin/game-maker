# `model-paint-layers/` —— **模型真实交付的「背景层」**（票 38 的真图回归）

这 5 张是**已付费**的生图接口真跑产出的**背景层原图**，原封不动拷进来 —— 不是重画的、不是合成的、不是桩。
它们与隔壁 [`model-paint/`](../model-paint/) 是**同一条纪律、不同的形状**：那边是**单帧 / 多帧**（物体 + 底），
这边是**背景层**（一条带 + 留白，或者一张本来就该铺满的底）。

为什么必须分开收：**背景层是两种相反的东西** —— `layers[0]`（最远层）本来就该铺满，抠它是错的；
其余层必须留白，不抠它是错的。同一条判据不可能同时对这两半（票 38 §2）。

⇒ 两条从真字节里读出来的结论：
1. **`#ff00ff` 5/5 在容差 30 下 0 像素**（加上第三次真跑那 9 张 = **14/14**）——
   声明色**不再是抠底依据**（票 38 的 Q3）。
2. **按众数色抠会把最远层打到门禁之下（三张全中），在非最远层上却正好是对的。**
   ⇒ 判据必须**按层分**，不能一条走到底。

⚠️ **判据本身还没定**（票 38 第二轮）：上面那两列只是**读数**，不是断言。
⚠️ **上游依赖**：这些颜色是 **`gemini-2.5-flash-image`** 在 **2026-09-30** 与 **2026-10-09** 两跑里交付的。
**换模型 / 换供应商 ⇒ 偏移会变 ⇒ 这 5 张的读数与实际脱节。**
那时的处置**不是**把断言放宽到「怎么画都算过」，而是：**重量一批真图、把这 5 张换掉**。
