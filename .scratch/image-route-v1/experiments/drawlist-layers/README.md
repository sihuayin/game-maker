# 实验：**drawlist 那条路**的最远层与逐层描述

[票 02](../../issues/02-layer-has-no-description.md) 的收尾。两轮，提示词在中间**改过一次**：

| 版本 | 提示词 | 量的是什么 |
|---|---|---|
| `v1` | 对每一层都说「没东西的地方留空」，**没有最远层的例外** | 逐层描述有没有用/有没有害 |
| `v2` | 加上「**最远那一层要铺满**」（`assetTask`，`cec9bf2` 之后） | 那一句有没有把缩带治住 |

## 跑什么

```sh
node .scratch/image-route-v1/experiments/drawlist-layers/run.mjs [每个臂跑几次]
node .scratch/image-route-v1/experiments/drawlist-layers/run.mjs --from-disk   # 不花钱：从磁盘上已有的包重新汇表
```

⚠️ **要花钱**（一个样本 = 一笔文本调用 —— 一个资源一次画完三层）⇒ 不住 CI。
⚠️ 这条路上**覆盖率是能读的**（与生图那条不同）：drawlist 由自己的光栅器画，没有抠图那一环。
⚠️ `pack` **永不覆盖** ⇒ 两版提示词的包都在磁盘上（`pack/v1` 与 `pack/v2`），
   `--from-disk` **按版本分开报** —— 混成一张表就是拿两次不同的实验当一次。

## v1：逐层描述**没有把两臂分开**

| 层 | 对照（摘掉逐层描述） | 处理（带上） |
|---|---|---|
| `sky` | 100 / **56.1** / 100 / 100 % | 100 / 100 / 100 / 100 % |
| `wall` | 55.8 / 35.7 / 48.1 / 59.3 % | 31.7 / 52.6 / 41.5 / 44.9 % |
| `ground` | 22.2 / 11.1 / 17.8 / 14.8 % | 11.1 / 22.2 / 11.1 / 13.3 % |

⚠️ **3/4 对 4/4 —— 两臂分不开**（这么小的样本本来也分不开）。**不能**说逐层描述治了什么。
⚠️ 而处理组那 4/4 全满，**多半不是「逐层描述」这个机制在起作用**：
   那份配方的天空描述里**逐字写着「天空铺满整块画布」** —— 那正是票 51 量过的那个
   **行文上的补丁**（「只拆掉那一句 ⇒ 100%」），不是结构上的修法。

## 而它顺手照出一处**真的缺**

对照里那一张 **56.1%** 的最远层是**缩带**（`rect y:0 h:150`，占 270 的 55.6%）——
即：**这条路也会缩带**，而 `assetTask` 里**没有最远层的例外**
（生图那条 `backgroundLayerPrompt` 有，那是票 51 加上的）。
一张最远层 56.1% 的包，按票 50「最远层必须画满」那条**会被拒**。

⇒ 补上那一句（`cec9bf2`），重跑：

## v2：最远层 **3+3 全满**

| 层 | 对照（3 个样本） | 处理（3 个样本） |
|---|---|---|
| `sky` | 100 / 100 / 100 % | 100 / 100 / 100 % |
| `wall` | 37.0 / 55.6 / 61.5 % | 39.2 / 34.1 / 56.3 % |
| `ground` | 14.8 / 8.9 / 21.5 % | 31.1 / 22.6 / 23.7 % |

- **缩带没了**（6/6 全满，v1 是 7/8）· 近层照旧都不满（门禁要的正是这个）。
- ⚠️ 这仍然只是 **6 个样本**，而且是**前后对照**（不是同一时刻的 A/B，没控住模型自身的波动）。
  「把它治住了」这句话在这个样本量上说不出口；说得出的是：**带上它之后没再出现缩带，也没伤到近层**。

## 与票 51 的关系

票 51 的 §3.3 自己更正过一次：「我过度推断了一次……**那条路线没有这个毛病**」。
⇒ 那条结论**在它当时那份提示词下成立**；而这条路**能**缩带，
且 `assetTask` 缺了生图那条路有的最远层规则 —— 已就地补记在票 51 里。
