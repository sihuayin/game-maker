# 来源范围与使用授权的核验方式

Type: grilling
Labels: wayfinder:grilling
Status: resolved
Owner: codex (2026-11-19)
Blocked by: —
Map: ../map.md

## Question

如何规划本仓库正式交付及历史产物的来源追溯范围，分别验证本地读取、后续验证、归档及 fixture 使用所需权限？外部来源的来源、使用和导入授权如何作为独立前置条件记录？

## Resolution

用户于 2026-11-19 确认：

1. 优先追溯有交付记录的仓库内正式 site、pack 与历史 run；逐项记录检查位置、版本与未覆盖区域。复用既有 20 个配置的筛选记录，不重复同类扫描；不宣称搜索穷尽。
2. 逐来源分别记录本地读取、执行验证、证据归档、作为 fixture 使用的授权依据与状态。沿用会话中已明确的只读授权；某用途缺少依据时，阻止该用途及依赖它的工作并记录缺口，不将一个用途的授权推定为其他用途的授权。
3. 外部来源须先记录来源身份、权利人或授权依据、允许用途、限制与导入授权；相应权限明确前不下载、导入或运行验证。记录缺口本身不表示取得授权。

本决定只规定核验方式，不授权实际追溯、导入、执行或新建 fixture。真实交付关系仍须满足“真实交付与来源证据的准入判据”。
