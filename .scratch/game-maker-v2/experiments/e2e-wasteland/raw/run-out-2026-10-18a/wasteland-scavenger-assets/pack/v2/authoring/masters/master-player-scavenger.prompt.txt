# 这个角色是谁（**八个字段，一个都不许漏**）
- `id`（**内部键** —— ⚠️ **不要把它画进图里**（图上不许出现任何文字））：`player-scavenger`
- `identity`（**它是谁** —— 这是全世界唯一说得出这一格的地方（世界语法里只有「角色怎么画」，没有「谁」））：一个在废城街区里活了很久的拾荒者，白天沿着地面与轨道条带一路向右，翻窗钻进空楼捡别人不要的东西；他不记得自己从哪来，只知道停下来就会被饿死或被什么东西撞上。
- `silhouette`（形态语言（**画法**：头形、边缘、量感），不是数值比例）：方块堆叠的矮壮身形，肩宽略大于躯干；背上的方形包袱与肩同宽、收在上背，不再向侧面压出巨大的方鼓包；头与肩之间留出可读的领口；站立时膝盖微沉、重心前倾，随时要迈步跑开。
- `face`（脸部画法）：两只等大的方形眼睛，间距适中、位置略高、完整露出；眼睛下方围一条深色半脸围巾，遮住下半脸；没有嘴与鼻。
- `clothing`（穿着）：深色短袖上衣压着一条横过腰部的浅色布带；裤腿被截短成两段方柱，脚上是一双边缘硬直的矮筒靴；短檐帽不再压住眼睛，帽檐与眼睛之间留出清楚的缝。
- `gear`（携带物 / 器械 / 佩戴物）：一只与肩同宽的方形拾荒包袱，用两条布带绑在背上；腰侧挂着一个开口朝上的小布袋；一副挂在额前的护目镜，镜片是唯一的高亮黄色

# 画成什么样
- **全身入画**：从头到脚都在画面里（脚下不要被画布切掉），四周只留**很窄**的一圈空白。
- **正视、正交投影**：不画透视、不画斜侧、不画角度。
- **中性站姿**：双臂自然垂下、双脚并拢站在**同一条水平线**上（所有动作都从这个姿态出发）。
- 这个角色的**外接矩形**长宽比必须**精确**是 72 : 108（宽 : 高）——
  交付管线会把它两方向独立缩放到 72×108 像素，比例不对就是硬拉伸。
- 画法：**硬边色块**、边缘干净利落、不要抗锯齿、不要柔边、不要渐变、不要写实照片质感、
  不要体积光、不要景深。
