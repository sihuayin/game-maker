# 票 67 探针：「意图里的机制**全都**挑不出对家」—— 这个角上**到底有没有合法输出**

**为什么要有它**：票面的结论是一句很强的话 ——
「**这个角上没有合法输出**：**唯一能过 gate 的路，正是散文禁止的那条**。」
那句话由**两条散文规矩**（`game-design/prompts.ts:191` 的「至少一条」＋ `:194-196`「挑不出对家就整条省掉」）
与**一条 gate**（`contracts/game-design.ts:255-259`）推出来。而「**合法**」这个词横跨**散文**与**机检**两侧 ——
本探针把候选的四条路**真的喂进 `buildDesign`**，看机检那一侧各判什么。

顺带量三件票面引了但没量的事：盘上 12 对真产物的样子（①）、重采样到底是不是**盲的**（④）、
仓库**自己的**测试 fixture 把哪条路当正例（⑤），以及 13a 那处「疑似」的真实归因（⑥）。

⚠️ **2026-10-14 补了一轮量**（同一份探针追加一节，见下面「⭐ 补量」⑨–⑫）：
第一轮量的是**判决**（四条路各判什么），补的这四行量的是**判决之外**的三件事 ——
那四条路**各要几发付费往返**（⑨）、两条路在**人眼前**长得一样吗（⑩）、
那两句相反的话**住在哪**（⑪）、散文第 1 条与 gate ④ 对得齐吗（⑫）。

## 四条最要紧的读数

1. **票面那句强话在机检那一侧不成立，在散文那一侧成立**：
   过 gate ④ 的路**不止一条**（B / C / D 都过），散文**只禁了 B**，对 C / D **一个字没说**。
   ⇒ 真正的缝是：**「非空」是硬要求（规则 1 + gate ④），而在这个角上「非空」只能靠顶替或新加凑出来** ——
   散文禁了前者、没提后者。
2. **顶替是唯一能被沉默接受的路**：②B 逐字 `ok: true`；而 ⑤ 量到**仓库自己的 fixture**就是一次顶替，
   还被当作「负判据不许误伤正例」的那个正例。⇒ 这个角上模型的**最省事行为**与**最安全行为**是同一个。
3. **这个角比票面说的近得多**：它的入口不必是「回合制战斗 + 技能树 + 对话」——
   ⑥ 量到 13a 那次真实地撞在 R12 上，缺的那一条是**一句布景**（`wasteland-bg`「废土背景」）。
   而 ①b 量到 **5/12 份意图**把实体 id 又登记成机制 id（那一半今天有 gate）；
   「一句话布景」那一半**没有任何 gate**（`mechanics[].name` 是 `z.string()`，「是不是机制」没定义）。
4. ⭐ **补量最要紧的一条：这个角是四支路里唯一「又贵又说不清」的一支**（⑨⑩⑪）——
   A 花 **3 发**（同一个 body 盲重发三次）、退的码与 C / D **一样是 4**、
   落到人眼前的却是一句**说岔了的话**（「没干活」）；而 C / D 只花 **1 发**就换来那句**诚实的报文**。
   ⇒ 「把那个角的代价调平」这条路上，**这个角今天不只是说不清，还最贵**。
   ⚠️ 而 ⑪ 量到：那两条打架的规矩**不在两份面之间**（票 54 的形状），
   **在同一句模型每发都读的话里** —— 工具说明里隔 4 行，台账里**同一行**。

## 本探针证明不了什么

- **改了散文或文案之后模型会不会写对** —— 免费手段证不了，归**票 23**，另出报告 + **逐次明确同意**。
- **那个角（全都挑不出对家）在真跑里发生过没有** —— **没有（n=0）**；盘上 12 份真设计的 `mechanics`
  长度是 4 / 5 / 5 / 5 / 5 / 5 / 7 / 8 / 8 / 8 / 8 / 9，**一份 `[]` 都没有**；
  而 13a 那份**从没落盘**（票 55 的容器在它之后才落地 ⇒ 盘上 `design-attempts.json` **0 份**）。
- **②里那份「角上的意图」是构造的**（把 13b 那份真意图的 `mechanics` 换成三条挑不出对家的）——
  它的**形状**是真的（过 `GameIntentSpecSchema`），但它**不是**某一跑的真实产物。
- **⑨ 那五格是「假 `fetch` 驱动真的 `compileDesign`」**：走的是**真代码**（真循环、真 gate、真 R12、真账），
  由探针**替上游**回话。⇒ 它量的是**链的行为**，不是**模型的行为** ——
  「模型在真跑里会不会写出 `mechanics: []`」它证不了（那是票 23）。
