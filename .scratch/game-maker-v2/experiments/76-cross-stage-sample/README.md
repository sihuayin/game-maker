## 量的是什么

入参走 `packages/contracts/dist/layer-coverage.js` 的**真函数**（`auditLayerCoverage` · `layerDrawnSize`），
视口 `480×270`（`DEFAULT_VIEWPORT`）· 世界 `1440×270`（骨架 `ops.ts:618` 逐字）·
每层标称 `480×270`（三份实物逐份都是它）。

| 节 | 问 |
|---|---|
| ① | 三处实物（段 A 样板 · 真产物 13e / 13h · 手写夹具）逐层裁一遍 |
| ② | 样板要改成什么才**在任意世界宽下都过**（三支逐支试） |
| ③ | 样板那个形状**在多宽的世界里才刚好过**（解临界值） |
| ④ | 仓库测试语料里 `sky` 的 `parallax` 取值分布 |

## 三条最要紧的读数

1. **四份带层的背景里，唯一不合规的就是段 A 那段样板**（sky p0.3 不铺 ⇒ 最坏剩 192px）；
   两份真产物**独立地**都抄了它（sky p0.1 / 中层 p0.4，各剩 384 / 96px）；
   **通过整条链的那份夹具是手写的**（sky **p0**）—— **不在任何提示词里**。
2. ⭐ **同一个 `0.3` 在本仓出现两次**：`prompt.ts:494` **教**模型写 `sky parallax 0.3`，
   而 `packages/demo/tests/site.test.ts:104-107` **把合规夹具的 sky 改成 0.3** 来证明它必须被拒。
3. **样板那个形状只在世界不比视口宽时才过**（世界 481 就拒）⇒ 它其实在教一个**不滚动的单屏游戏**，
   而段 B 与 Destination 要的是横向滚动。
