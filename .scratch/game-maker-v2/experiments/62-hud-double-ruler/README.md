## 两条最要紧的读数

1. **票面那句「两个不同的越界」不成立**。第十二跑那个盒子 `(-28,246)` 里，世界尺响在 **y**
   （`246+32 = 278 > 270`）—— 它**根本不查负 x**（④/⑧ 实测）。所以报出来那两条里，
   **y 那次越界是被两把尺子各说了一遍**；「左边界 28px」只有视口尺说了。
2. **「世界尺响 ⇒ 视口尺响」在世界 ≥ 视口时是 100%**（1728 个盒子，0 个反例）。
   ⇒ 世界尺对 `hud.panel` 的判决**整个含在**视口尺的判决里，它不是第二意见，是**同一条意见的第二遍**。
