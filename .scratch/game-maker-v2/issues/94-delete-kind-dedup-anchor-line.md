## 1 · 立案现场（逐字 ＋ 本轮实测）

`packages/assets/src/ops.ts:875-876` —— 横版 `compileRuntime` 问话面里的**一整节**：

```
# 锚点的意思（照这个摆）
${[...new Set(manifest.assets.map((a) => `${a.kind}：${anchorHint(a.anchor)}`))].join(" · ")}
```

⭐ **Q4 那句「并列输出相互矛盾的信息」本轮在盘上量到了**（用四份包的真锚点重算这一行，逐字）：

| 包 | 这一行印出来的逐字 |
| --- | --- |
| `last-train`（夹具） | `… · **ui：左下角 · ui：左上角**` |
| **13h 真跑** | `… · **ui：左上角 · ui：{x:0.5, y:0.5}（归一化锚点…）**` |
| **13e 真跑** | `… · ui：{x:0.5, y:0.5}（归一化锚点…）`（四件 ui 塌成一条） |
| `counter-siege`（夹具 · 塔防） | `… · ui：左上角`（四件 ui 塌成一条） |

⇒ ⭐ **同一个 `kind` 在同一条提示词里被印成两种互相打架的锚点**（`last-train` 与 13h 各一次），
而**没有任何东西**告诉模型这两条说的是不同的资源；`last-train` 那份甚至**一件 ui 是左下角、另一件是左上角**。

⭐ **「丢失资源身份」也量到了**：逐资源的 `resourceBrief`
（`ops.ts:690` 每件都印 `锚点 {x:…, y:…}`）**已经**把真锚点一件一件印过；这一行**只按 `kind` 汇总**，
⇒ `counter-siege` 四件 ui、13e 四件 ui **各塌成一条**，读的人分不出是哪一件。

⚠️ **零测试覆盖**：`grep -rn "锚点的意思\|anchorHint" packages/*/tests` ⇒ **零命中**
（`packages/*/tests` 里只有 `character-dna` / `visual-world` 那两处**无关的**「去重」）。
⇒ **删掉它不会红任何一条测试**，也不会被任何闸报出来。

⚠️ **只有横版这一处**：`grep -n "new Set" packages/assets/src/{ops,prompt}.ts` ⇒ 全仓**唯一**那条锚点去重在
`ops.ts:876`；塔防那一份（`tdConfigPrompt`，`ops.ts:1149`）**没有同款**，**不在本票射程内**。

⚠️ **上游那句仍然成立**：`ops.ts:845` 铁律 3 那句「本包的锚点含义**见下面每条清单**」指的是
**逐资源的 `resourceBrief`**，不是这一节 ⇒ 删掉本节**不影响**它。

## 2 · ⚠️ 两格待裁（都在动手之前要清）

### Q1 —— 那个抬头 `# 锚点的意思（照这个摆）` 一起删吗？

- **(a) 一起删**（抬头 ＋ 正文两行）—— ⚠️ 只删正文会留下**一个有抬头、没有内容**的空节
  （紧接着就是 `# 手感：…`），那比原样更糟。
- **(b) 只删正文，留抬头**。
- **(c) 别的。**
➡️ **本票默认读法：(a)**（「整句删除」在这一节里 = 抬头 ＋ 内容一起走）。⚠️ 但**票面不预先指定**。

### Q2 —— 与[票 90](90-anchor-convention-to-authoring-side.md) 的 **Q6** 怎么分工？

`anchorHint`（`ops.ts:698`）是**模块私有 `const`**、全仓**只有这一个调用者**（就是 `:876`）；
⇒ 删掉 `:876` 之后它**零调用者**，而本仓**没有** `noUnusedLocals`、**没有** linter
（`tsconfig.base.json` 逐字核过）⇒ **它会一声不响地留在原地**。

- **(a) 本票一次删干净**：抬头 ＋ 正文 ＋ `anchorHint` 函数本身（三处一处改动）。
- **(b) 本票只删 `:875-876`**，函数留给票 90 的 Q6 去删（两票各删各的）。
- **(c) 别的。**
➡️ **本票默认读法：(a)**。理由：票 90 的 Q6 逐字写的是「**一旦获准删除**，删除整个函数**及其调用点**」，
而**那次「获准」就是本票**；分成两票意味着**同一处改动要两次授权**，而中间那一轮盘上会**留一个死函数**。
⚠️ **但这一格必须现在说清**：若选 (b)，票 90 的 Q6 与票 94 **会先后改同一个文件**。
