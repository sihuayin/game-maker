## Question

`hud.panel` **同时被两把坐标语义不同的尺子判**：

```
contracts/src/game-config.ts:348   inWorld("hud.panel", boxOf(…))
                                   └─ 用**世界**那把尺（:343 报「世界 ${W}×${H}」）
contracts/src/screen-space.ts:58   auditScreenSpace 用**视口**那把尺
                                   └─ ⚠️ 它自己的报文就写着「⚠️ 尺子是**视口**不是 world.size」
```

⇒ 第十二次真跑里**同一个盒子** `(-28, 246) 72×32` **报了两条**：

```
· hud.panel: 落在世界之外（世界 1440×270；这个盒子是 (-28,246) 72×32）
· hud.panel: HUD 活在**屏幕空间**，必须整个落在视口 480×270 内；而它的盒子是 (-28,246) 72×32。
             ⚠️ 尺子是**视口**不是 world.size
```

⚠️ **但先把一件事说清，免得把「两条不同判据」误读成「同一条说了两遍」**：

```
inWorld（世界尺）  响在 b.y + b.h > H          （它**不查负 x**）
auditScreenSpace  响在 b.x < 0                （视口尺查下界）
```

⇒ 同一个盒子，**两条报的其实是两个不同的越界**（下边界 8px / 左边界 28px）。
**所以「是不是重复报告」本身就是待裁的第一问**，不是已定的前提。

## 已经量到的（别重新量）

- `game-config.ts:348` 的实参是 `boxOf(config.hud.panel.at, config.hud.panel.size, config.hud.panel.asset)`
  —— ⚠️ **用的是配置里的 `size`**（尺寸那条见[票 63](63-hud-panel-size-not-reconciled.md)）。
- 本包 `hud-bar-backdrop` 真实 **32×16**、锚点**中心 `{x:0.5, y:0.5}`**、`kind=ui`。
- 骨架示例那一格：`{ at: {x:8, y:262}, size: {w:72, h:32} }`（`assets/src/ops.ts:558`）。
- ⇒ 中心锚点下算出来的盒子 `(8 − 36, 262 − 16) = (−28, 246) 72×32` —— **与两条报文一字不差**
  （票 40 那条「示例错了，模型就会错」原样复现）。
- ⚠️ **而「这个盒子为什么会跑到负 x」还有一层**（`2026-10-13` 顺带量到、**未裁、本票不裁**）：
  `game-config.ts:331-333` 的注释写着「**HUD 面板是左下角**（`{x:0, y:1}`）」，而这份真包里
  `hud-bar-backdrop` 的锚点是**中心** `{x:0.5, y:0.5}`（`asset-recipe.json` 里就是这么写的 ⇒
  **锚点由配方层写**）—— 若它真是左下角，`box.x = 8`，**负 x 根本不会出现**，也就只剩 y 那一条。
  ⇒ **一处「注释说包的约定是 X、而链产出的包是 Y」** —— 它与「哪把尺子」是**两个**问题，
  ⚠️ **本票只登记、不认领**（是否另开一问，等人裁）。
- `inWorld` 的其余调用点：`terrain[${i}]` · `entity "…"` · `player.at`（`game-config.ts:345-348`）。
- 定位：第十二次真跑 · 段 B（`raw/run-out-2026-10-13e/`）。

## 要裁决的（留给下一轮 grill，此处只列边界）

1. **这是不是重复报告？** 同一个事实用两把尺子说两遍，对失败现场的人是**帮助**还是**噪音**？
2. **`hud.panel` 该由哪把尺子判？** 世界尺架在一件**屏幕空间**的东西上，**是不是错配**？
   ⚠️ 注意两条报的是**不同越界**（见上）—— 所以可能的答案不止「去掉一条」，
   也可能是「两条都对，只是措辞该说清各管哪一半」。
3. **若该去掉一条**：去掉哪条？`inWorld` 的其余三个调用点**受不受牵连**？
   ⚠️ 它们（`terrain` / `entity` / `player.at`）**确实是世界空间的东西** —— 世界尺在那儿是对的。
