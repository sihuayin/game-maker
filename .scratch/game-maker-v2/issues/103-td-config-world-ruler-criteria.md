## 1 · 这一票治的是什么

票 83 的验收 §6 第 3 条写着「**塔防那两处各有判据**（阳性 + 阴性）」。核过之后：

- 票 83 新加的 **4 条**契约测试（`packages/contracts/tests/td-config.test.ts:193-243`）**全部**看着
  `auditTdWorldSize`（「世界必须 == 视口」那一族）—— **没有一条**看着 `td-config.ts:445-448` 的四边 `inWorld`；
- ⇒ 那条裁决保留下来的**塔防近端硬失败**，今天**没有判据看着**。

⭐ **两发探针实测**（均已从备份还原，`md5 = 6e55b24624b3c685a655bb5b454e1e4d`，
`git diff -- packages/contracts/src/td-config.ts` 为空）：

| # | 弄坏什么 | 读数 |
| --- | --- | --- |
| A | 删掉 `:446` 的 `b.x < 0 \|\| b.y < 0` | `npx vitest run packages/contracts/tests/td-config.test.ts` ⇒ **48/48 全绿** |
| B | 把整条 `inWorld` 变成空函数 | 同样 **48/48 全绿** |

⚠️ 全仓 `grep -rn "落在世界之外" packages/*/tests` 只命中 `game-config.test.ts` 与
`demo/tests/td-site.test.ts` —— 塔防配置那一份**一次都没被断言过**。

⚠️ **它不是在验恒真**：插槽/柜台的锚点若不是零（塔防包里的 17 件非 UI 资源全是 `{0.5,0.5}`），
`at.x < w/2` 就会长出负盒子（票 81 第一轮 §2.8）。⇒ 它是一条**活着但没人看着**的判据。

## 2 · 要做的（射程由票 81 的 Q2(a) 钉死）

在 `packages/contracts/tests/td-config.test.ts` 里补**阳性 + 阴性**两条判据：

1. **阳性**：盘上那份真关卡（`fixtures/td-configs/counter-siege.json`）过 `auditTdConfig` 时，
   四边 `inWorld` **一声不响**（真配置没有被这条尺子误伤）。
   ⚠️ **现有那条「真关卡零硬失败」不构成这条判据** —— 把整条 `inWorld` 删掉它照样绿（探针 B）。
2. **阴性**：构造一份配置，让**槽**（或**柜台**）的盒子带负数 ⇒ `severity: "error"`，且报文命中
   `落在世界之外`。
   ⚠️ `at` 由 schema 保证非负（`game-config.ts:32` 的 `nonnegative`）⇒ 负盒子只能从**锚点**来：
   取一个锚点为 `{0.5,0.5}` 的资源、把 `at.x` 推到 `w/2` 以下（例如 16px 宽的资源、`at.x = 0` ⇒ `box.x = -8`）。
   ⚠️ 构造时要**只让这一族响**（别让「插槽压走道」「离走道太近」等先把它盖掉 —— 票 83 第六个探针的教训）。
3. ⭐ **证伪实测（本票的成败线）**：新测试写好后，把 `:446` 的 `b.x < 0 || b.y < 0` **删掉**，
   新测试必须**当场红**；随后从备份还原，`md5` 与动手前**逐字节相同**。
   ⚠️ 只写一条绿的测试**不算** —— **加判据不会自带判据**（票 83 §3.2 的原话）。

## 3 · 边界（本票**不做**）

- **只加测试**：`td-config.ts` 的 `inWorld` 判决与报文**一字不改**；不合并两份 `inWorld`
  （票 81 第二轮 Q1 = (a)）；不抽共用报文。
- ⚠️ **只补近端那一格**：票 81 第二轮 Q2 的裁定逐字是「塔防配置**近端**硬失败的阳性与阴性判据」。
  探针 B 量到**远端那一半也零判据** —— 那是同一份报告里的**另一格**，本票**不代裁、不顺手补**；
  要补须另一次点头 / 另一张票。
- **不动横版**（`game-config.ts` / `demo/src/site.ts` / `game-config.test.ts` 一行不碰）。
- **不动 `fixtures/**`**（阴性夹具在测试里就地构造；动 fixtures 要另一次授权 —— 票 64 的教训）。
- **不动 R 表**（R17）· **不改提示词** · `packages/qa` 判据一行不碰 ·
  `game-maker.local.json` 一个字不动 · **不执行任何付费真跑** · **不提交** · **不关票**。

## 4 · 施工前要拍板的

1. ⚠️ **远端那一格补不补？** 探针 B 证明整条 `inWorld`（含远端）今天零判据。本票按裁定只补近端；
   若要让本票同时补远端，需要**另一次逐字点头**（或另立一票）。
2. **阴性夹具落在槽上还是柜台上？** 两者都走同一条 `inWorld`（`:512` / `:540`）。
   槽更容易构造（`at` 可直接改），但柜台那一格今天只在 `coreA && coreAt` 时才判（`:538`）——
   若选柜台，要确认那条守卫没有把负盒子吞掉。
3. **阳性那条要不要与现有「真关卡零硬失败」合并？** 分开写更贵，但合并会让「这条判据看着谁」
   再次变模糊。

   `check:deps` ✅ 9 包；`check:links` 绿。
