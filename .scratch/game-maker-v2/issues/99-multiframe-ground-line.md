## Question

### 2 · 免费诊断（生产函数 · 只读 · 零上游）

```text

segmentRow（按实测众数色抠完）→ **1 块**，bbox = (0,0,1344,768)

把 y ≥ 671 裁掉再分块 → **4 块**：
  (60,346,162×325) · (398,270,188×401) · (761,288,187×383) · (1142,346,128×325)
```

⚠️ `pack.ts:841` 那条报文的第二段（「若那个众数色其实是主体…」）在这个现场是**指错方向**的。

### 3 · prompt 的原文与落点

`packages/assets/src/prompt.ts:441-446`（多帧动画提示词）：

```text
画一张**横排的游戏角色动画分解图**：横向排开 N 个格子……
⚠️⚠️ 最重要的一条，请先读它：**背景必须是纯色 ${bg}**，整张图铺满，不要渐变、不要噪点、
   不要纹理、不要图案、不要格线、不要编号、不要文字、不要水印、不要边框。
   N 个角色之间要留出**明显的空隙**（背景色露出来），这样才切得开。
```

同文件 `:461`：

```text
- N 个角色的**大小一致**，脚底落在**同一条水平线**上，不要有的高有的矮。
```

⚠️ **两句话的交互是嫌疑**：prompt 说了「不要格线」，也说了「脚底落在同一条水平线上」——
模型把后者画成了一条**实体横线**。⚠️ 这只是嫌疑，不是已证的因果（n=1）。

### 1 · 五问的冻结内容

**Q1 = (c)：两侧都改。** 动画提示词按 Q2 的三处改；分块侧加一条**失败才触发**的救援：

1. **只在第一次分块数 `≠ spec` 的 N 时**尝试；正常图的行为一字不改。
2. 找**底部**的连续横带：逐行覆盖率 ≥ **90%**、至少 **3 行**；只认贴着画面底部 / ink 底边的那一段（17c 是 97 行 · 最高 100%）。
3. 把带子**从原图和探针里一起裁掉**（不是只让分块忽略），再分块 —— 否则交付帧会带横带（§2 读数 ①）。
4. 重分块**正好 N 块**才接受；否则抛原来的错，并在报文里加一句「也可能是一条贯穿底部的横带」。
5. 接受时**留下观察**（`pack` 的 summary 或 `res.audit`）：印出「忽略了底部 H 行、覆盖率 X%」，**不许静默**。
6. `segmentRow` 的默认行为不改；纯函数（带子检测 / 裁剪）放 `sheet.ts`，策略（何时重试）放 `pack.ts`。

**Q2：三处逐字**（都在 `animationSheetPrompt` 内）：

- `prompt.ts:446` 之后加：
  ```
     画面里**除了这 ${n} 个角色本身的像素，别的都不要有**：不要画地面、地平线、街道、
     阴影、底座连线，也不要画任何横贯画面的线或带。
  ```
- `prompt.ts:461` 整句换成：
  ```
  - ${n} 个角色的**大小一致**，脚底**对齐到同一个高度**，不要有的高有的矮。
    ⚠️ 只是**位置对齐** —— **不要**在脚下画线、地面、地平线或阴影来表示对齐。
  ```
- `prompt.ts:455` 的 DNA 分支里、`dnaBrief` 之后加：
  ```
  ⚠️ 上面身份描述里若提到「地面 / 街道 / 来回走」之类，那是在说它**怎么动**，
     不是让你把地面画出来 —— 这一张图里**只有 ${n} 个角色**。
  ```
- ⚠️ 不动母版提示词、不动 DNA、不动世界语法。

**Q3：四条验收**（全部免费）：

1. **提示词见证**：断言渲染后的动画提示词**含**新句、**不含**旧句 `脚底落在**同一条水平线**上`；正控「脚底 / 对齐」仍在；负控另外两张模板**不含**新句。**先只加断言、源码一行不动 ⇒ 红；再改 prompt ⇒ 绿。**
2. **合成分块测试**：N 个分开的角色 + 底部满宽横带 ⇒ pack 成功、N 帧，**且交付帧里横带颜色 0 像素**；阴性：真正连在一起的角色仍抛「检测到 1 块」；阴性：带子 + N-1 个角色仍抛；正常图行为不变。
3. **免费回放 17c 真现场**：`/tmp` 探针（不落库）按失败账本顺序注入 `generateImage`，跑 `buildAssetPack` ⇒ patrol 出 4 帧、帧内无横带。**零付费、真实失败图**；它证明「分块那一半」，**证明不了模型会不会照提示词做**。
4. **不声称「模型会照做」**：那要一次真跑（票 23），另出报告 + 逐次明确同意。

**Q4：不裁资源级重生成。** 分块救援是对**已付钱的那张图换一种切法**，不是重生成，不触发 R13；无自动重试 / 修复循环；免费回放只做 `/tmp` 探针，**不新增「复用失败图」的生产机制**；下一次付费真跑另出报告 + 明确同意。
