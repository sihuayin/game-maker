## 1 · 这一票治的是什么（⑰ 的读数）

真发出去的那份 body 里，「# 资源包清单（**只许用这里面的东西**）」那一节**每一件 ui 都逐行写着真实尺寸**：

```
- `hud-lost-slots` · ui · 72×32px · 锚点 {x:0, y:1} · 动画：（无动画，引用时不必给 anim）
- `hud-pip` · ui · 12×12px · 锚点 {x:0, y:0} · 动画：（无动画，引用时不必给 anim）
```

而同一份 body 里：含 `scale9Borders` = **false** · 含 `九宫格` = **false** · 含 `ninePatch` = **false**。
⇒ ⭐ **config 那一步的模型看得到「包里的真实尺寸」，看不到「这件是不是九宫格」**。
而 `manifest` 里**有** `scale9Borders`（`contracts/src/assetpack.ts:155`）⇒ **判据拿得到、模型拿不到**。

⇒ ⚠️ 于是票 63 新落的那条判据 `auditPanelSize`（`contracts/src/game-config.ts:365`，调用点 `:436`；塔防同款 `td-config.ts:554`）
**只能是事后复核**：模型写 `hud.panel.size` 时**不知道**自己指的那件资源是不是九宫格，
而「声明 ≠ 包」合法与否**全看那半个条件**。

## 3 · 施工前要拍板的（⚠️ 没有一件是「照着做」就完的）

- **ⓐ 两处同批，还是抽成一份共用？**
  ⚠️ 票 63 的 **Q6** 裁过「横版与塔防的同类字段必须由**同一条**判据约束」（所以 `auditPanelSize` 抽出来共用了一份）——

- **ⓑ 补上去的那个词叫什么？** 仓库里**两个名字在飘**：
  契约与包里是 **`scale9Borders`**（`contracts/src/assetpack.ts:155`），
  而配方那一步给模型的散文用的是 **`"ninePatch":{"left":4,"right":4,"top":4,"bottom":4}`**（`assets/src/prompt.ts:501-502`）。
  ⇒ ⚠️ **选错名字就是把一个模型不认识的说法塞进清单** —— 而这一票的**全部意义**就是「让模型看得见」。
  （⚠️ 本票**不改契约**，只决定**清单上印哪个词**。）
- **ⓒ 印到什么程度？** 只印「**是 / 不是九宫格**」，还是连**四边内缩的那四个数**一起印？
  印数的话模型就能推出「这件资源在某个尺寸下会不会变形」；但那个数得是**人读得懂**的写法（配方那一侧给的正是四个数）。
- **ⓓ 谁看着它？** 仓库现成先例：`packages/assets/tests/prompt.test.ts:20` 与 `:27` **两条 `it`** 正向钉着配方那句散文
  —— 🔴 ⚠️ **那是另一个包、另一次调用**；本票的判据要落在**本票改的那两处**的测试文件里（`assets/tests`，但不是同一组 `it`）。
  ⚠️ 要不要**正负两条**（「印了九宫格」+「没有 `scale9Borders` 的那件不印」）由本票定。
- **ⓔ 只补清单，还是顺带在提示词里说一句「声明 ≠ 包时它必须是九宫格」？**
  ⚠️ 票 63 的 **Q2 只裁了「补进资源清单」** —— 要不要把那条规矩本身也写进 config 那一步的提示词（第 8 条那一族）
  **不在那次裁定里** ⇒ 若要做，**是这一票要单独裁的**，而且它比 ⓐ–ⓓ 大：
  那是**新增一条规矩**，不是把既有事实印出来。
