两个独立的问题：

1. **管线缺陷（免费可修）**：生图在角色头顶留下了极淡的字形；抠底没去掉，切帧的包围盒把它算进去
   ⇒ idle/jump 被压到 71/108 高、头顶飘 6 颗碎点。run 帧没有碎点，所以满高 —— 游戏里**站住时角色会缩小**。
2. **角色设计本身**（要改 DNA + 重生图）：`character-dna.json` 当前逐字要求
   「包袱体积必须大于躯干」「头几乎陷进肩膀」「帽檐压得极低」「只有两只方形眼睛」；
   `stylespec` 是「方块人 / 抽象五官 / 禁止描边」⇒ 产出就是"大棕包袱 + 空白方脸 + 方块身体"。
   换管线清理只能去掉碎点，**不会让这个设计变好看**。

## 2 · 新 DNA（建议，施工时逐字落进 `run/v<N>/character-dna.json`）

`player-scavenger`：

- **silhouette**：方块堆叠的矮壮身形，**肩宽略大于躯干**；包袱**与肩同宽、背在上背**，不再向右后侧压出巨大的方鼓包；
  头与肩之间留出可读的颈/领口；站立时膝盖微沉、重心前倾。
- **face**：两只方形眼睛，**间距适中、完整露出**；**一条深色半脸围巾**遮住下半脸；没有嘴与鼻；帽檐改短，不遮眼睛。
- **clothing**：深色短袖上衣 + 浅色腰带；裤腿截短、矮筒靴；**短檐帽**；**护目镜挂在额前（黄色镜片）**。
- **gear**：**与肩同宽的方形包袱**（不再是躯干的两倍）+ 两条布带；腰侧小布袋；护目镜。
- **palette**：沿用现有色板；亮色集中在护目镜 / 眼白 / 腰带扣（`palette:3` 黄色），其余保持深色。
- **visualConstraints**：
  - 包袱**不得宽于肩部**；
  - 帽子不得遮住眼睛，眼睛方块完整可见；
  - 全身轮廓在 **72×108** 的框里一眼分出：头 / 肩 / 躯干 / 两条分开的腿；
  - 禁止文字、编号、水印与画面上的任何字形。

同步改 `asset-recipe.json` 里 `master-player-scavenger` 的 description（它是动画表生成时的参考图）。
