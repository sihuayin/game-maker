## 0 · 一句话

「一个资源里两条动画同名」今天**没有任何一条判据叫这个名字**（创作侧、交付侧都没有）。
票面写「后果会被另一条判据抓到」—— ⭐ **本轮量下来，这句话只对了一半，而错的那一半正好决定这一票怎么裁**：

```text
drawlist / image  →  帧名由动画名**派生**（`<资源 id>.<动画名><序号>`）⇒ 必撞帧名
                     ⇒ 交付侧那条「帧名重复」拒它 —— 但**钱已经花完了**，而报文点的是**帧名**

import            →  帧名是**配方自己写的**（`source.sheet.names`），**不由动画名派生**
                     ⇒ ⭐ 那份**真产物过了 `parseAssetPack`**（探针 ③ 实测）
                     ⇒ 「帧名那条已经够了」这个理由，**在一整条策略上不成立**
```

⚠️ 而 `import` 那份**合法**产物的下场是：**读者静默解到第一条**（`resolvePackRef` 的 first-match-wins），
两条动画**都变成了四条帧的合体**；唯一会说话的地方是**链尾的 QA**，而它说的是**帧数**（「要 2 帧，实际 4 帧」）。

⇒ 于是这一票要裁的不是「要不要多一条好习惯」，是**三件**：
**① 花费之前拒** · **② 报文点到病根** · **③ 交付侧契约到底收不收这种包**。

### 2.1 ⭐ ③ 为什么逃得掉（机制 · 这一票最要紧的一处）

帧名的**由来在两条路上不是一回事**：

```text
drawlist / image   pack.ts:542  const plan = framePlan(spec)          ← 帧名**由动画名派生**
                   prompt.ts:148-155  name: `${spec.id}.${a.name}${a.frames > 1 ? i + 1 : ""}`
                   ⇒ 两条同名动画**必然**产出同名帧 ⇒ 交付侧 :197 拒它

import             pack.ts:903  const names = src.sheet?.names ?? [spec.id]   ← 帧名**配方自己写**
                   pack.ts:907  animOf.set(n, a.name)  ← 分组名才是动画名
                   ⇒ 帧名两两不同**照样**成立 ⇒ 交付侧**没有任何一条**碰得到它
```

⚠️ 而 `pack.ts:930` 那一步是**按状态名过滤**的：
`frames: frames.filter((f) => f.state === a.name).map((f) => f.name)`
⇒ 两条同名条目**筛出同一批帧** ⇒ ⭐ **不是「一条多余」，是「两条都变成了同一条」（而且是合体）** ——
票面这句话在 `import` 这条路上是真的，在 `drawlist` / `image` 上则根本产不出包。

### 2.2 ⚠️ 而它**终究会被抓到** —— 抓到的地方在链尾

- `pack` 把 `audit`（`auditAssetSpec` 的结果）**返回给调用方**，**不当场失败**
  （`pack.ts:136` 逐字：「**有内容不等于失败** —— 交调用方决定」）。
- ⚠️ 而**调用方不看它**：`ops.ts` 的 `pack` 那一段**没有一处**读 `res.audit`（本轮 grep 过）。
- 真正会说话的是 **QA**：`qa/src/visual.ts:119` 逐条调 `auditAssetSpec`，
  落成 `constructive-constraint` 的 `severity: "error"` ⇒ **一条会阻断的判据**。
- ⇒ 于是这份包的结局是：**过契约 · 过 pack · 过 config · 过了站点**，最后**死在 QA**
  （链上最后一段），而报文说的是**帧数**，不是**名字重复**。

### 2.3 顺带量到的两条（与本题相邻，供裁时区分）

- ⚠️ **配置层那一条不是同一条规矩**：`game-config.ts:312-330`（票 61）判的是
  「`player.anims` **三格**解析到三个**互不相同**的动画」—— 那是**引用**的唯一性；
  本票问的是**声明**的唯一性。⚠️ 而它**兜不住**本题：`[idle, idle, run, jump]` 三格照样互不相同。
- ⚠️ **`playerAnimationGate`（`ops.ts:314`）也兜不住**：它的 ② 逐字写着
  「**多出来的路不管** —— 合约只要求『包含』」（`ops.ts:184`）⇒ `[idle, idle, run, jump]` **过得了它**。
  ⭐ 但它在**花费之前**跑（紧挨 `parseRecipe`，同在 `plan-assets` 那一发里）——
  **「花费之前」那个窗口今天确实存在，而且已经住着一条同类判据**。
