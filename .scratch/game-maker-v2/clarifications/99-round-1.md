━━━ Q1 · 治在哪一侧？━━━

(a) 只改 prompt：改 prompt.ts；模型不一定照做，已付钱的图救不回来。
(b) 只改分块（票面字面：segmentRow 忽略 >90% 的行）：改 sheet.ts；会静默通过，且像素不裁则每帧带横带（见 ①）。
(c) 两侧都改：一张合并施工票；要分别定验收。
(d) 不改，只登记：0；2/18 的形状会再撞，13h 那种静默通过已经发生过。

➡️ 推荐 (c)，但 (b) 那一半不是票面的字面做法，而是一条「失败才触发的救援」：
1. 只在第一次分块数 ≠ spec 的 N 时才尝试；正常图的行为一字不改。
2. 找底部的连续横带：逐行覆盖率 ≥ 90%，至少 3 行（17c 是 97 行 · 100%）。只认贴着画面底部/ink 底边的那一段，不认画面中间的横线。
3. 把带子从原图和探针里一起裁掉（不是只让分块忽略），再分块 —— 否则交付帧会带横带（① 量到 207–240/240）。
4. 重分块正好 N 块才接受；否则抛原来的错，并在报文里加一句「也可能是一条贯穿底部的横带」。
5. 接受时留下观察：在 pack 的 summary 或 res.audit 里印出「忽略了底部 H 行、覆盖率 X%」，不许静默。
6. segmentRow 的默认行为不改；纯函数（带子检测/裁剪）放 sheet.ts，策略（何时重试）放 pack.ts。

⚠️ 如果你更想按 (b) 的字面做（永久改 segmentRow、不为失败单独开路），请在裁定里明说 —— 那会把「只忽略行」的横带问题一并接受，我不推荐。

━━━ Q2 · prompt 的措辞写死到哪一步？━━━

➡️ 推荐三处，逐字如下（都在 animationSheetPrompt 内）：

① prompt.ts:446 之后加一句（在「这样才切得开」下面）：
   画面里**除了这 ${n} 个角色本身的像素，别的都不要有**：不要画地面、地平线、街道、
   阴影、底座连线，也不要画任何横贯画面的线或带。

② prompt.ts:461 整句换成：
- ${n} 个角色的**大小一致**，脚底**对齐到同一个高度**，不要有的高有的矮。
  ⚠️ 只是**位置对齐** —— **不要**在脚下画线、地面、地平线或阴影来表示对齐。

③ prompt.ts:455 的 DNA 分支里加一句（在 dnaBrief 之后）：
⚠️ 上面身份描述里若提到「地面 / 街道 / 来回走」之类，那是在说它**怎么动**，
   不是让你把地面画出来 —— 这一张图里**只有 ${n} 个角色**。

· 三条可以同时成立，不打架：没有写「必须留白」，只写「不要画那条线/地面/阴影」。
· 不动母版提示词、不动 DNA、不动世界语法。
· 如果你只想留最少一条，我建议留 ① + ②；③ 是针对 identity 里「地面」那句的定点补丁，收益有嫌疑但未被证。

━━━ Q3 · 施工票的验收（免费部分）━━━

➡️ 推荐四条：
1. 提示词见证（prompt.test.ts）：断言渲染后的动画提示词含新句、不含旧句「脚底落在**同一条水平线**上」；正控「脚底/对齐」仍在；负控另外两张模板不含新句。按票 94/98 的纪律：先只加断言、源码一行不动 ⇒ 红，再改 prompt ⇒ 绿。
2. 合成分块测试（packages/assets/tests/）：N 个分开的角色 + 底部满宽横带 ⇒ pack 成功、N 帧，且交付帧里横带颜色 0 像素（这条是关键，防「只忽略行」）；阴性：真正连在一起的角色（无带子）仍抛「检测到 1 块」；阴性：带子 + N-1 个角色仍抛；正常图行为不变。
3. 免费回放 17c 的真现场：/tmp 探针（不落库）注入一个按失败账本顺序读 authoring/{masters,generated} 的 generateImage，跑 buildAssetPack ⇒ patrol 出 4 帧、帧内无横带。零付费、真实失败图。这证明「分块那一半」；证明不了模型会不会照提示词做。
4. 不声称「模型会照做」：那要一次真跑（票 23），另出报告 + 逐次明确同意。

━━━ Q4 · 与票 33 的关系 ━━━

➡️ 推荐：本票不裁「资源级重生成」。
· 分块救援是对已付钱的那张图换一种切法，不是重生成，不触发 R13。

━━━ Q5 · 13h 的「沉默通过」怎么办？━━━

➡️ 推荐：另开一张票（Blocked by: 99），不并进本票施工。
· 它是另一条机制：两块时相对宽度过滤不生效（sheet.ts:87 的 boxes.length >= 3）⇒ 角落碎块被当成一帧；且那条地面线是 88.5%，不在本票 90% 的射程里。
