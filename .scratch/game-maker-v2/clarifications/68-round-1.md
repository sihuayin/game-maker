## 一、根问题

### ❓ Q1 — **那句话改成什么口径？**

票面给了三支。读完 ② / ③ / ③′ / ⑧ 之后，它们的**真实代价与效果**是这样：

| | 写成什么 | 读者读到什么 | 动到什么 |

| **(a)** | 把假因果**换掉**：「写了这一份**过不了 schema** ⇒ 整份判失败、重采样 3 次全白费、退 4」 | 一条**真的**关于管线的陈述 | 提示词 1 句 |

| **(d)** | 别的 | | |

⚠️ **两条必须说清的读数**：

- **(b) 有一个 ③ 量出来的副作用**：那个错机制（「`quantize.ts` 兜得住」）**本来就是假的**，
  并置等于把它**再写进模型的上下文一遍**。提示词每一发都重读，模型没有记忆 ⇒ 并置换不来任何东西，
  只换来一个更长的假陈述。⇒ 我的推荐是 **(a) 换掉，不并置**。
- **那句话比票 54 那处更靠近「没代价」**（⑧）：54 改口前的原话是「判 = 一个中性的观察」，
