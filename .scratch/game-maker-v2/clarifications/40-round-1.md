// ⚠️ **一个 unit 一次调用**。unit 的划分与 drawlist 路线的 `framePlan` **对称**（票 43）：
//   · animation → 一个**动画**一个 unit
//   · 分层背景 → **一层**一个 unit
//   · 其余 → 一个资源一个 unit
const bgLayers = spec.kind === "background" ? spec.layers : undefined;
const units: { anim?: string; layer?: {…}; frames: number; raw: string }[] =
  spec.kind === "animation"
    ? spec.animations.map((a) => ({ anim: a.name, frames: a.frames, raw: `authoring/generated/${spec.id}.${a.name}.png` }))
    : bgLayers

      : [{ frames: 1, raw: `authoring/generated/${spec.id}.png` }];

❓ **Q2** - **抽出来之后，`pack` 那边回收哪一部分？**

「可复用的**分类**」与「`pack` 自己的做法」必须划清，否则抽出来的是一层壳：

| 东西 | 是分类吗 | 归谁 |
|---|---|---|
| 切几个单元、每个单元是哪个 `anim` / 哪个 `layer`（`index`/`total`/`tileX`）、每个单元几帧 | ✅ **是** | **共享函数** |
| `raw`（`authoring/generated/<id>.<anim>.png` 这类**落盘文件名**） | ❌ | `pack` |
| `prompt` 怎么按 `anim` / `layer` 拼 | ❌ | `pack` |
| `batches` 怎么分批 · 抠底用什么色 | ❌ | `pack` |

- **A. 窄切**：共享函数只返回**分类**（`{ anim?, layer?, frames }[]`），`pack` 拿到之后再补 `raw`。
- **B. 宽切**：连同 `raw` 一起搬进共享函数（「一个单元落在哪个文件」也算分类的一部分）。

➡️ **推荐 A**。理由：`raw` 是**落盘布局**，它跟 `authoring/` 那棵树是一件事，
而那棵树是 `pack` 的产物形状 —— 把它挪进 `contracts` 等于把「包长什么样」也说成契约事实。

❓ **Q6** - **判据怎么立？**（⚠️ 这条最容易做成一枚**假牙**）

票面那一问是「要不要一条测试钉住『两个数来自同一段代码』」。**要**，但**写法有讲究**：

- **❌ 假牙写法**：测试里也 `import` 同一个函数，断言「函数算出来的 === 检查点报的」。
  ⇒ 两边都是**同一个函数**，函数一错**两边一起错、测试照绿**。这正是票 38 那三条断言栽过的形状
  （「拿这两张证明用的是众数色是一颗假牙」）。
- **✅ 有牙齿的写法**（推荐）：断言
  **检查点报的那个数 === 桩生图器**实际被调用**的次数**。
  `told`（桩看见的调用）是**观测到的真相**，与「谁算的」无关 ⇒ 函数错了它就红。
  `recipes-sweep.test.ts:169-171` **已经**是这个形状了（`expect(told).toHaveLength(want)`），
  只是它的 `want` 是**手抄的第二份实现**。
- **✅ 另一条腿**：给共享函数本身一份**手工列出的**用例表
  （四类 spec × {无 layers / 有 layers / N 个动画} × {image 母版 / import 母版}），
  期望值**写死**在测试里，**不由函数推出来**。

➡️ **推荐**：① 把 `recipes-sweep` 的 `want` 改成**从共享函数取**（这样「第二份实现」消失，
而 `told` 那半边仍然是独立观测）**并且**② 另加一份写死期望值的表。
⚠️ **但这里有个取舍要你裁**：① 做完之后，「`pack` 用的分类被改错」这件事就**只由 `told` 兜**
—— 如果 `pack` 与共享函数**同时**被改成错的（比如有人把分类挪回 `pack` 内部），
这一条**看不出来**。要防它，得让某条判据**锚在 `pack` 那一侧的调用次数上**（`told` 就是），
或者让共享函数有一份**不依赖它自己**的期望表。请裁：**够不够**，还是要再加一条「`pack.ts` 里不得出现第二份分类」的见证判据
（本仓库有先例：票 05 那条「剥掉注释之后找 needle」的见证判据）。
