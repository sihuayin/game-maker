# 需求（产物 A 的输入之一）

做一个横版跳跃小游戏，叫《交接班》(Shift Change)。

**世界**：一间被革命军接管的废弃杂货店。玩家扮演店主 **Odin Haraldsson**，
在店铺打烊前把货架上的东西抢救出来。场景是店铺内景：服务窗口、长长的柜台、
密密麻麻的货架、墙上挂着的宣传海报和通风管道。

**玩法**：从左往右跑，跳过堆在地上的货箱和垃圾袋，踩到漏电的地板会掉血，
沿途捡起还没被没收的罐头和药瓶。跑到底就通关。

**玩家**：一个中年男人，戴着绿毛线帽、穿灰绿旧夹克，胸口挂着一块发光的 CRT 显示屏。
他需要：站着不动、走路（要循环的）、跳起来三种动作。

**要的资源**：
- 玩家角色（上面那三种动作）
- 可以横向拼接的地面平台
- 两种障碍：堆叠的货箱、漏电的地板
- 两种拾取物：罐头、药瓶
- 一整张店铺内景背景
- 一块挂在店里的招牌（带边框的，上面可以写标语）
