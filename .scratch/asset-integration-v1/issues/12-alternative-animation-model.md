## Question

选定 2.5 之后的动画替代模型。**先定义统一的动画验收标准，再比较候选**；不要先争论哪台模型更好。

### 1. 验收标准（先定）

至少覆盖：

- **帧间几何**：同一动画 2 帧及多帧的 bbox 宽度 / 位置 / alpha 掩码差异；给出阈值
  （可参考 2.5 基线：0.4% alpha 差、455 vs 454 宽）。
- **肉眼一致性**：轮廓、姿势、比例、明暗在联系表上是否读作同一角色。
- **交付质量**：背景众数色稳定性、透明边缘 / 抠底质量、1px 描边保真、色板吸附。
- **成本**：每个**合格动画**的成本（含重试与不合格帧），不是单张图成本。
- **多参考图稳定性**：风格图 + 母版两张参考图下的角色保真。
- **可用性与回退**：停服 / 限权 / 区域可达性；模型不可用时的回退顺序。

### 2. 候选与比较方式

候选至少：

- `gemini-3-pro-image`（Interactions，JPEG；约 4× 2.1 成本）；
- Vertex（PNG 入口；需核对 3.x 是否兑现 `imageOutputOptions.mimeType`）；
- 其他 provider（OpenAI 等；先核对跨帧一致性）。
- 2.5 legacy 仅作临时旁路，不进入长期候选。

**先出零付费研究 / 对比设计**；任何真跑（付费 smoke / 跑批）另立票、另出预算、逐字点头。

### 3. 不做

- 不切换默认模型；不改 `game-maker.local.json`；不引入 3-pro / Vertex 的付费调用；
- 不把共享框当作已批准的动画一致性修复；
- 不把 fixtures 重基线到任何未通过验收的模型。

## 验收

- 一份动画验收标准（可量化 + 人眼判据）。
- 一张候选对比计划（成本 / 风险 / 所需验证 / 付费闸）。
- 若需要付费验证，明确另立票，不在本票预授权。

## 边界

- 不发起任何付费调用；不改源码 / 配置 / fixtures；不迁移默认模型。
- 本票只定标准与比较计划；选型结论与付费验证分开走。

## Answer（2026-10-21 · 人裁）

默认模型切换或整包跑批。**

### 采纳的七条（原文）

| 问题 | 裁定 | 核心约束 |
| --- | --- | --- |
| Q1 验收单位与样本量 | 采纳 | 动画为验收单位；筛查 2 帧、资格 3+3 帧、决赛全循环 |
| Q2 机械闸阈值 | 采纳 | 采用绿／黄／红三档；任何红灯帧都使整个动画失败 |
| Q3 人眼闸 | 采纳 | 清单式检查、A/B/C 盲标、目标 FPS 循环预览 |
| Q4 成本与预算上限 | 采纳，预算上限不等于调用授权 | 按每合格动画成本比较；每阶段仍需单独预算报告和逐字批准 |
| Q5 候选资格与回退 | 采纳 | 资格先行；主候选 → 备候选 → 停止／冻结复用；不得静默切换 |
| Q6 决策规则与证据 | 采纳 | 资格筛选 → 机械闸 → 人眼闸 → 存活候选排序；质量优先 |
| Q7 比较顺序 | 采纳 A | 先做零付费官方资料研究，最多 2 个候选进入付费筛查；筛查需另行授权 |

### 执行口径（原文）

#### 1. 机械闸的边界值

| 指标 | 绿灯 | 黄灯 | 红灯 |
| --- | --- | --- | --- |
| Alpha 掩码差 | ≤ 1.0% | > 1.0% 且 ≤ 3.0% | > 3.0% |
| 干净 bbox 宽度差 | ≤ 2% | > 2% 且 ≤ 5% | > 5% |
| 位置漂移 | ≤ 1% | > 1% 且 ≤ 3% | > 3% |
| 背景众数色 L1 | ≤ 10 | > 10 且 ≤ 20 | > 20 |
| 调色板色数 | ≥ 14 | 不设黄灯 | < 14 |

- 任一帧出现红灯，整个动画直接失败，不得通过其他帧的平均表现抵消。
- 黄灯不能自动通过，必须由人眼复核并记录逐项结论。
- `off-palette = 0`、无残留地面线或碎点、轮廓边界深色占比 ≥ 50%，作为交付机械硬门槛。
- 机械全绿只代表通过机械闸，不代表整包验收通过。候选比较仍须检查角色身份、姿势、风格和循环稳定性。

#### 2. 样本与决赛规则

- **筛查**：`scavenger-actor.idle1/idle2`，只淘汰明显不合格的候选。
- **资格**：拾荒者 idle 的首／中／尾 3 帧，加敌人 patrol 的首／中／尾 3 帧。
- **决赛**：拾荒者 idle 全 4 帧、敌人 patrol 全 6 帧，并提供目标 FPS 的循环预览。
- 每个候选必须使用同一组提示词和参考图；评审材料隐去模型名称，以 A/B/C 盲标。
- 决赛通过仅代表该候选具备进一步评估资格，不能自动授权整包生成或批量迁移。

#### 3. 成本与模型决策

每合格动画成本：

`该候选全部付费（含重试与被拒帧） / 最终通过验收的动画数`

同时报告合格帧率（yield）。零合格动画时，不报告为零成本，应标记为无合格产出，并披露总花费。

| 阶段 | 预算上限 | 授权状态 |
| --- | --- | --- |
| 筛查 | ≤ $0.50 / 候选 | 未授权 |
| 资格 | ≤ $2.00 / 候选 | 未授权 |
| 决赛 | ≤ $4.00 / 候选 | 未授权 |

这些数字是上限，不是支出许可。每次付费验证仍须先提交书面预算报告，并取得单独、明确的逐字批准。

#### 4. 候选资格与回退

候选需满足：决策后六个月内无已知停服日、具备明确可用的接入路径、不受仅历史用户限制、
输出格式兼容获准的资源处理路径、官方定价可查，以及官方文档明确支持两张参考图。

候选排序先看人眼质量；只有质量相近时，才比较每合格动画成本和运营风险。
主候选、备选和停止／冻结复用之间的切换，必须经过新的书面裁定，不由运行时自动决定。
