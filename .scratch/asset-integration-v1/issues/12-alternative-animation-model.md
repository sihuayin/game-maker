## Question

选定 2.5 之后的动画替代模型。**先定义统一的动画验收标准，再比较候选**；不要先争论哪台模型更好。

### 1. 验收标准（先定）

至少覆盖：

- **帧间几何**：同一动画 2 帧及多帧的 bbox 宽度 / 位置 / alpha 掩码差异；给出阈值
  （可参考 2.5 基线：0.4% alpha 差、455 vs 454 宽）。
- **肉眼一致性**：轮廓、姿势、比例、明暗在联系表上是否读作同一角色。
- **交付质量**：背景众数色稳定性、透明边缘 / 抠底质量、1px 描边保真、色板吸附。
- **成本**：每个**合格动画**的成本（含重试与不合格帧），不是单张图成本。
- **多参考图稳定性**：风格图 + 母版两张参考图下的角色保真。
- **可用性与回退**：停服 / 限权 / 区域可达性；模型不可用时的回退顺序。

### 2. 候选与比较方式

候选至少：

- `gemini-3-pro-image`（Interactions，JPEG；约 4× 2.1 成本）；
- Vertex（PNG 入口；需核对 3.x 是否兑现 `imageOutputOptions.mimeType`）；
- 其他 provider（OpenAI 等；先核对跨帧一致性）。
- 2.5 legacy 仅作临时旁路，不进入长期候选。

**先出零付费研究 / 对比设计**；任何真跑（付费 smoke / 跑批）另立票、另出预算、逐字点头。

### 3. 不做

- 不切换默认模型；不改 `game-maker.local.json`；不引入 3-pro / Vertex 的付费调用；
- 不把共享框当作已批准的动画一致性修复；
- 不把 fixtures 重基线到任何未通过验收的模型。

## 验收

- 一份动画验收标准（可量化 + 人眼判据）。
- 一张候选对比计划（成本 / 风险 / 所需验证 / 付费闸）。
- 若需要付费验证，明确另立票，不在本票预授权。

## 边界

- 不发起任何付费调用；不改源码 / 配置 / fixtures；不迁移默认模型。
- 本票只定标准与比较计划；选型结论与付费验证分开走。
