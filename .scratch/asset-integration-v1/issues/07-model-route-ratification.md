## Question

05 已给出推荐路线：**冻结 2.5 产物；战略路线 = Interactions API + JPEG 解码，模型 `gemini-nano-banana-2.1`；
2.5 legacy PNG 只作已批准小补丁的临时旁路。** 本票请人逐条裁定：

1. **接受 JPEG 作为未来上游格式？** 在「不切 Vertex / 不换 provider」的前提下，Interactions 的输出枚举
   只有 JPEG（v1 / v1alpha / v1beta discovery 一致）；这是唯一可走的路。
2. **长期默认模型定 `gemini-nano-banana-2.1`？** 对比：3.1-lite 更便宜但官方明说「不为多参考图优化」；
   3-pro 约 4× 成本且像素风收益未经证实；3.1-flash 已 deprecated。
3. **2.5 的内部截止日**：官方三份口径互相打架（2027-03-15 / 2026-10-02 / 「未弃用」）；
   报告建议内部按 **2026-12-31** 停止依赖 2.5 跑新批次。
4. **是否批准零付费施工票**（`jpeg-js` 解码 + Interactions 请求改 JPEG + 测试；约 0.5–1.5 人日；
   顺序必须先解码器、后改请求）。
5. **是否批准同动画 2 帧的 smoke 预算**（2.1 · Interactions · JPEG；≤4 发 / ≤$0.16 / ≤15 分钟），
   用来验证真实 JPEG 编码 + 逐帧裁框抖动。付费仍须逐字点头。
6. **fixture 重基线**：smoke 通过后，**替换**现有 16 张 2.5 `model-paint*` fixture，还是新增一套 2.1 fixture？
   （报告建议替换；不要放宽断言来「兼容」新模型。）
7. **若 smoke 看到帧间抖动**，是否追加「动画级共享裁框」施工票（`ImportOptions.trimBox` 已有，
   `pack.ts` 未暴露）？

## Answer（2026-10-20 · 人裁）

**逐条裁定（原文）：**

| 问题 | 最终裁定 | 生效条件 / 授权边界 |
| --- | --- | --- |
| Q1 JPEG 作为未来上游格式 | A：接受 | 以同动画两帧 smoke 通过作为验收门槛；若出现不可接受的帧间抖动，先评估 Q7 |
| Q2 长期默认模型 | gemini-nano-banana-2.1 | 仅在 smoke 通过且 fixture 重基线完成后生效；此前不改默认配置 |
| Q3 2.5 内部截止日 | 2026-12-31 | 截止后新批次不得依赖 2.5；已逐字批准的小补丁可在迁移完成前使用 legacy 旁路 |
| Q4 JPEG 零付费施工 | 批准立票并授权限定范围内开工 | 仅限解码、MIME 分派、Interactions 请求格式及指定测试；不含付费调用和默认模型切换 |
| Q5 两帧 smoke | 批准预算上限 | 最多 4 发、$0.16、15 分钟；执行前仍须提交书面预算报告并获得逐字确认 |
| Q6 fixture 重基线 | 替换现有 16 张 fixture | 单独立付费票；预算另批，旧 fixture 在新一批验收前保留 |
| Q7 动画级共享裁框 | 条件性立票，不立即开工 | 仅当两帧对照出现肉眼不可接受的轮廓呼吸或位移漂移时触发 |

**由本裁定产生的票：**

- [08. JPEG 解码 + Interactions 请求改 JPEG](08-jpeg-decoder.md)：零付费；开工范围已由 Q4 限定。**可开工。**
- [09. 同动画 2 帧 smoke](09-two-frame-smoke.md)：阻塞于 [JPEG 施工票](08-jpeg-decoder.md)；预算上限已批，但**执行前仍须书面预算报告 + 逐字点头**。
- [10. 2.1 fixture 重基线](10-fixture-rebaseline.md)：阻塞于 [同动画 2 帧 smoke](09-two-frame-smoke.md)（若 [动画级共享裁框](11-shared-trimbox.md) 触发则也阻塞于它）；**另行付费预算**。
- [11. 动画级共享裁框（条件性）](11-shared-trimbox.md)：阻塞于 [同动画 2 帧 smoke 票](09-two-frame-smoke.md)；仅在触发条件满足时开工，否则关票。

**没有授权的事（逐字边界）：**

- 07 本身没有发出任何付费调用、没有改源码、没有改 `game-maker.local.json`。
- JPEG 施工票的开工授权只覆盖该票列出的范围：仅限解码、MIME 分派、Interactions 请求格式及指定测试；不含付费调用和默认模型切换。
- 同动画 2 帧 smoke 的付费：最多 4 发、$0.16、15 分钟；执行前仍须提交书面预算报告并获得逐字确认。
- fixture 重基线的付费：单独立付费票；预算另批，旧 fixture 在新一批验收前保留。
- 动画级共享裁框票：仅当两帧对照出现肉眼不可接受的轮廓呼吸或位移漂移时触发。

### 2026-10-21 · 09/11 的 C 裁定

- 2.1 未通过动画一致性验收：并集共享框后 alpha 差仍有 **7.1%**（2.5 基线 0.4%）；
  干净 bbox 宽 **650 vs 474**（2.5: 455 vs 454）。
- 按 Q2 的生效条件，2.1 **未成为动画默认**；JPEG 路径（08）保留为基础能力，不代表 2.1 获准用于动画生产。
- 动画继续用 2.5；2.5 内部截止 **2026-12-31** 不变；替代动画模型另立
  [12](12-alternative-animation-model.md)（先定验收标准）。
