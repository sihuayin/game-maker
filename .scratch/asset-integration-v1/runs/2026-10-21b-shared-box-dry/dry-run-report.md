## 结论先说

- 共享并集框把 2.1 的帧间 alpha 差从 **17.9% 降到 7.1%**（约 −60%），但仍是 2.5 基线（**0.4%**）的 **~18 倍**；
  平均框略差（8.0%）。
- 2.1 两帧的**干净 bbox 宽度本身就是 650 vs 474（相差 176 px，~37%）**；2.5 是 455 vs 454（相差 1 px）。
  ⇒ 剩下的差异是**模型逐帧绘制方差**（宽度 / 姿势 / 明暗），共享裁框只能规整坐标系，消不掉它。
- 按 09 的裁定「dry-run 仍不可接受 ⇒ C」，我的判读是：**C（拒绝 2.1 作为动画默认）**。
  共享裁框施工不足以把 2.1 拉到可接受的一致性；不应为它投入施工。
