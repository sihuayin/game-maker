# 07. 母版提示词说「管线会拉伸它」，而管线不会 —— 这句话留不留

> 派生自票 05 的裁定（2026-10-19）：母版回图比例只作观察；沿用时发现提示词里有一句假话。
> ⚠️ **立票 ≠ 批准施工**；本票只裁这句话的改法。

## Question

`packages/assets/src/master.ts` 的 `masterPrompt()` 写着：

> 这个角色的**外接矩形**长宽比必须**精确**是 ${canvas.w} : ${canvas.h}（宽 : 高）——
> 交付管线会把它两方向独立缩放到 ${canvas.w}×${canvas.h} 像素，比例不对就是硬拉伸。

而今天的管线**从不对母版做任何缩放**：母版不进交付包，只作为 `reference` 图片内联进动画生图；
动画帧是在抠底、裁到自身 ink bbox 之后才被 `downscaleArea` 缩放到 `spec.size` 的。

C/C2 的实测：请求 48×64，回来 864×1184 / 858×1178（2.7–2.9%），模型没有照这句「精确」做。

要裁的是这句话：

(a) **保留** —— 它是逼模型守比例的压力话术，即使字面后果是假的；
(b) **改成真话** —— 例如「后面每一次动画都会照这张图的头身比画」，不承诺管线会缩放；
(c) **删掉** —— 只留「外接矩形比例必须精确是 …」那半句。

## 边界

- 只改这一句；不改母版提示词的其它部分。
- 不跑付费上游；不修改任何生成行为。
- 立票 ≠ 批准施工；施工需另行点头。

## Answer

**一句话**：母版提示词里那句「外接矩形比例必须精确 = 画布比例、交付管线会两方向拉伸它」
是**假的且自相矛盾**的；改写为「画布是 W×H；后面每一次动画都会照这张图的头身比与形象画」。
资产提示词与多帧提示词里的同类句子**保持原样**（它们描述的是真实交付行为）。

### 逐字裁定（人裁 2026-10-19）

**Q1 = C · 采用推荐改写。** 明确母版画布尺寸为 `48×64`，并说明后续动画会参考这张图的头身比与形象；
删除「外接矩形比例必须精确为 48:64」及「管线会把它两方向独立缩放」的错误表述。
资产提示词与多帧提示词中的同类语句保持不变，因为它们描述的是真实交付行为。

**Q2 = A · 只裁定。** 写入 Answer、关票、更新地图；不修改 `master.ts`，不修改测试，
不发起上游调用或付费生成。本轮裁定不构成施工授权。

**裁定依据（逐字）**：母版是后续动画的视觉参考，不是交付管线中会被强制缩放的资源。
原句混淆了画布长宽比与角色本体外接矩形的长宽比，并虚构了母版的机械拉伸行为。
应保留真实有效的信息 —— 画布尺寸和动画对母版形象的参考关系，
同时删除错误的执行承诺与不合理的角色比例要求。

**范围边界（逐字）**：本轮只确认改写方向。实际修改及相应测试断言调整，须另行授权。

### 改写的方向（施工时用变量，`48×64` 是 C2 的实例）

把 `packages/assets/src/master.ts` 的 `masterPrompt()` 中这两行：

> - 这个角色的**外接矩形**长宽比必须**精确**是 `${canvas.w} : ${canvas.h}`（宽 : 高）——
>   交付管线会把它两方向独立缩放到 `${canvas.w}×${canvas.h}` 像素，比例不对就是硬拉伸。

替换为：

> - 画布是 `${canvas.w}×${canvas.h}` 像素（宽 : 高 = `${canvas.w} : ${canvas.h}`）。
>   后面每一次动画都会**照这张图的头身比与形象**画 —— 所以比例、轮廓、配色要画准。

### 依据（查到的）

- 母版从不被缩放、也不进交付包：它只作为 `reference` 图片内联进动画生图。
  ⇒ 「管线会拉伸它」对母版是假的。
- 同样的句子在资产提示词（`prompt.ts:409-410`）与多帧提示词（`prompt.ts:480-484`）里是**真的**：
  那边会裁到 ink bbox，再由 `downscaleArea` 两方向缩放到 `spec.size`。
  ⇒ 这三处不能一起改；本票只动母版那一处。
- 「外接矩形」是第二个错误：母版提示词要求角色本体 bbox 比例 = 48:64 = 0.75；
  实测 C2 母版画布 858×1178（0.728），**角色 bbox 约 0.425**（476×1121）—— 差 43%。
  一个双臂自然垂下、背背包的站姿角色本来就窄，不可能等于 0.75；
  而 `masterRatioReading` 量的是**画布**比例，不是 bbox 比例。
- 母版提示词**唯一**提到画布尺寸的地方就是这句假话；直接删掉会连「画布是多大」一起丢掉。
  ⇒ 改写必须保留画布尺寸。
