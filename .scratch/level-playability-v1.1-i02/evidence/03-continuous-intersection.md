## 4. 形式化定义

### 4.1 三角波（I-00 §4.1–4.2）

给定 `at`、`distance > 0`、`periodMs > 0`：

```
φ(t) = ((t mod P) + P) mod P ,  u = φ/P
p(t) = at + distance · k(u),   k(u) = 2u        (u < 1/2)
                                     2 − 2u     (u ≥ 1/2)
```

- `p(0) = at`；折返点 `t = nP/2`；`p(P/2) = at + distance`；两端不停留。
- 单调段速度 `±v`，`v = 2·distance / periodMs`；折返点处导数不存在，只取左右极限。
- 负时间与多周期由模运算覆盖；三角波对 `t` 是偶函数：`p(−t) = p(t)`。
- `distance ≤ 0` ⇒ 原地不动（与 P0 同义）。

### 4.2 AABB 与严格相交（geometry.ts:14-15）

AABB 为 `{x, y, w, h}`，`x` 左边缘、`y` 上边缘。

```
overlapsStrict(a,b) ⇔ a.x < b.x+b.w ∧ b.x < a.x+a.w
                    ∧ a.y < b.y+b.h ∧ b.y < a.y+a.h
```

贴边、角接触、零面积接触一律**不算撞**。本实验**不用 ε 缩小该谓词**：`1e-12` 的正面积重叠仍算撞（用例 P6/S12），因为 I-00 §6.1 把相切语义冻结为 `overlapsStrict`。

### 4.3 容差 ε（I-00 §6.4）

```
ε = max(1e-9, 1e-9 × (xMax − xMin))
```

本实验把 ε 只用于**显式传入的区间阈值** `intervalTol`（默认 0）和门宽判定，不用于碰撞谓词本身。ε 的两种可能用法及其语义后果见 §7.2。

## 5. 解析算法

### 5.1 切段

玩家左边缘在段内线性：`x(t) = x0 + s_p·(t−t0)`。Hazard 锚点 `p(t)` 在折返点之间线性。取切点集合

```
{t0, t1} ∪ { k·P/2 : t0 < k·P/2 < t1 }
```

每个子区间内 `p(t)` 线性，斜率由**中点**所在单调段精确给出（`±v`，不取折返点值）。切点数量 `≈ 2·(t1−t0)/P`，原型在超过 `1e6` 时显式报错 `too-many-cuts`，不静默退化。

### 5.2 单子区间闭式

Hazard 盒子在子区间内：`L(u) = L0 + s_h·u`、`R(u) = R0 + s_h·u`（`u = t−a`）。严格相交等价于两个线性不等式同时成立：

```
(1) x(u) + pw > L(u)   ⇔  c0₁ + c1₁·u > 0,  c0₁ = xa + pw − L0,  c1₁ = s_p − s_h
(2) x(u)      < R(u)   ⇔  c0₂ + c1₂·u > 0,  c0₂ = R0 − xa,      c1₂ = s_h − s_p
```

每个不等式在 `u ∈ [0, dt]` 上的解是开区间：

```
c1 = 0  : c0 > 0 ? [0, dt] : ∅
c1 > 0  : [max(0, −c0/c1), dt]
c1 < 0  : [0, min(dt, −c0/c1)]
```

两者求交，`hi − lo > intervalTol` 才记为一个碰撞开区间。**`c1` 用精确的 `=== 0` 判定**；不对速度差设绝对容差（P0 的 `|c1| < 1e-9` 在量纲上不成立，见 §8）。

### 5.3 合并与边界

- 子区间碰撞区间在切点处首尾相接时合并（S4：上升段 `(950,1000)` + 下降段 `(1000,1050)` → `(950,1050)`）。
- 真实安全窗口只要 `> 0` 就保留（S10 保留了 `1.005e-6 ms` 的窗口）。
- 开区间语义在折返点自然处理：仅在折返点相切 ⇒ 无碰撞（S3）；折返点两侧都撞但恰好相切于该点 ⇒ 两个区间之间留一个零测度“安全点”（构造见 §6.3 注）。

## 7. 数值稳定性与 ε 的语义后果

### 7.1 稳定性

- **无除以零**：`c1 === 0` 走精确常量分支；近零相对速度（S11，`1e-10 px/ms`）走一般分支，根 `−c0/c1` 很大或很小但都被 `[0,dt]` 夹住。
- **无隐式容差**：碰撞谓词、斜率判定、区间端点都不带 ε；唯一阈值是显式 `intervalTol`。
- **切点连续**：折返点邻域两侧位置连续（§6.2），子区间首尾位置一致，不会在切点产生缝隙或重叠。
- **可表示性下限**：双精度在 `|x| = 1e9` 处的间距为 `2.22e-7`，`5e-10` 的重叠**无法被输入表示**（实测 `1e9 + 4 − 5e-10 === 1e9 + 4`）。因此 I-02 实现应把坐标平移到局部原点；否则 ε 的世界尺度语义与浮点可表示性会脱节。

### 7.2 ε 的两种用法（事实，不是裁定）

1. **门宽 / 证据宽度**（I-00 明文）：`R − L > ε`。本实验只在此处使用 ε。
2. **碰撞区间宽度阈值**（P0 的做法）：`hi − lo > 1e-9`。这不是“数值保护”，而是**语义变更**：任何短于阈值的真实碰撞窗口都会被判成安全（X1：`2e-10 ms` 窗口；S9）。若该阈值取世界相对的 ε，则同一场景在小世界判撞、大世界判安全。

选 1 还是 2、以及阈值取绝对还是世界相对，属于 **I02-D3 / I02-D6** 的裁定范围；本实验只提供量化后果。

## 8. 与 P0 `segmentCollides` 的差异复核

P0 是 1D x-only（`y` 只做常量重叠检查），I-02 需要 AABB + y 区间；数学骨架相同（折返点切段 + 两个线性不等式）。差异共 6 处，全部**已定位到行，并可用一组开关精确复现**。

| 编号 | P0 行为 | 位置 | 与精确语义的关系 | 触发用例 |
| --- | --- | --- | --- | --- |
| D-P0-1 | `verticallyOverlaps` 用 `−EPS` / `+EPS` | `temporal-model.mjs:129` | y 重叠 `≤ 1e-9` 被漏判 | X2、nearCritical |
| D-P0-2 | `|c1| < 1e-9` 绝对钳位当作“速度差为零” | `:154` | 量纲错误；近零速度差下的长区间碰撞被漏判 | X3 |
| D-P0-3 | 区间非空判据 `lo < hi − EPS` | `:160`, `:220` | 短于 `1e-9 ms` 的碰撞窗口被抑制 | X1 |
| D-P0-4 | 折返点切点若落在端点 `1e-9` 内则跳过 | `:191` | 极短段跨折返点时把两段合成一段线性 | 代码事实（本次未构造出独立反例） |

### 8.3 随机差分

- 种子 `1337`，2000 例；参数取自整数/半整数网格（`at ∈ [−50,150]`、`distance ∈ {0,1,10,50,100}`、`P ∈ {100,200,1000,2000}`、`width ∈ {2,10,20}`、`anchorX ∈ {0,0.25,0.5,1}`、`dt ∈ {1,5,20,100}`）。
- 结果：both-hit `392`、both-miss `1608`、**exact-only `0`、P0-only `0`**。
- 用 §8 的 6 个开关复现 P0（`intervalTol=1e-9, slopeClamp=1e-9, constTol=1e-9, cutEps=1e-9, dtEps=1e-9, yMode='p0'`）：**不匹配 `0 / 2000`**。

结论：在常规参数区，P0 与精确语义**一致**；差异只在近临界区（短窗口、微量重叠、近零相对速度、lag pad）出现。因此 I-02 不能“照抄 P0 再加 y”，必须显式决定每处容差。

## 9. 对下游的事实输入（供 D1 / D3，不构成裁定）

- **F1 可行性**：闭式解存在、代价 O(切点数)，切点数 `≈ 2·span/P`；无迭代、无采样、无搜索。
- **F2 相切**：`overlapsStrict` 的开区间语义可以在连续时间上精确表达；贴边、角接触、零面积、折返点相切全部有确定结果。
- **F3 区间结构**：单个单调段内碰撞集是**一个开区间**；跨折返点需要合并，否则会把一个连续碰撞拆成两段。
- **F4 安全窗口**：解析解保留任意小的正安全窗口（实测 `1.005e-6 ms`），也能表达零测度安全点。
- **F5 ε 的语义重量**：把 ε 用作“碰撞区间宽度阈值”会改变碰撞语义；用作门宽阈值（I-00 明文）不会。两种用法的量化后果见 §7.2。
- **F6 lag**：`lagMs` 的 ∃δ 语义是**方向性**的；P0 的对称 pad 是保守超集。连续时间上精确处理 ∃δ 需要额外的切点/交点（滑动窗口的 min/max 是分段线性的 `min`/`max`），本原型**只**提供逐点可达区间的精确查询，未把它接入连续求解器。D2/D3 需要在“pad（保守）/ 精确 ∃δ（更复杂）/ 两档 lag 分别分析”之间裁定。
- **F7 坐标尺度**：`|x| ~ 1e9` 时 `1e-9` 量级的重叠不可表示；实现应在局部坐标帧内计算。
- **F8 P0 差异**：§8 的 6 处差异已可复现；若 I-02 复用 P0 骨架，必须逐条显式处理，不能默认等价。
