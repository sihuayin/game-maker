# inputs/ —— 人给的输入素材

这个目录放**人产出的输入**，不是产物。产物在 `out/`（gitignore）。

按 R10 / 票 35 的裁决：**管线永不调用生图 API**。需要手绘质感的位图由人在
**合规的交互式工具**里产出（Claude Code / Cursor 这类，条款明确允许），
文件放进这里，**管线只读不调**。

## 与 fixtures/ 的分工

| | 是什么 | 入库 |
|---|---|---|
| `fixtures/` | 仓库自带的**基准件**：参考图、StyleSpec、drawlist、配方样例 | ✅ |
| `inputs/` | **你**这一次要用的素材：生图产出、手绘 PNG | ✅（Q9 精神：只有 inputs/ 与 fixtures/ 入库） |
| `out/` | 跑出来的资源包 / 站点 | ❌ 全部 gitignore |

## 位图要求（实测得出的，不是偏好）

票 23 的原型实测过：让生图模型画「像素风」，交回来的是一张
**像素画风格的抗锯齿图** —— 1024×1024、**61152 种颜色**、边缘位置对任何 k 取模
都均匀分布（**没有整数像素网格**）。所以导入通道做的是**重建**一个网格，不是重采样。

输入图满足下面几条，重建的损失最小：

1. **主体与背景对比明显**、背景尽量近纯色 —— 抠背景只能按容差做（实测那类图的背景
   四角取样能拿到 4 种颜色）。**给透明底 PNG 更好**，那样连抠都不用。
2. **硬边、不要抗锯齿、不要渐变** —— 半透明边缘会被二值化掉，渐变会被量化掉。
3. **色数少**，越接近世界色板越好。导入位图会被**默认量化**到色板（票 23 裁决），
   量化不是免费的：实测把一张 1218×685 的场景图量化到 9 色，**100% 的非透明像素被改色**。
4. **尺寸不用迁就目标尺寸** —— 导入通道会面积平均降采样到 `spec.size`。
   给大图给细节是对的，但**别指望 32×48 装得下 1024×1024 的信息**。

## 目录约定

每个试件一个子目录，放它的配方与说明。配方里的 `ref` **相对配方文件**解析 ——
图上写 `"ref": "station-keeper.png"`，指的就是配方旁边那张图。
