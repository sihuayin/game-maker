## 1. 能力声明与边界

沿用 I-00 §1 的承诺边界，不扩大：

> 系统能够在**可信输入**与**确定性运动假设**成立的条件下，对**单个沿 X 轴运动**的 Hazard 进行受限时序可达性分析，并对安全窗口、正宽度永久封锁及证据不足作出符合既有三态语义的判断。

I-02 增加的是**内部算法核心**：

- 连续时间三角波 / AABB 求交；
- 安全通过 Witness（U9 与全相位 Winning Set 两条充分证书）；
- 永久封锁门证明；
- 垂直规避图割与 hop 加倍检查；
- 工作预算、确定性与内部降级。

**不包含**：

- 通用动态障碍物规划；
- 多移动 Hazard、Moving Platform、Danger 联合；
- Y 轴移动 Hazard；
- 跳跃 / 下落 / 重力与 Hazard 的精确时序耦合；
- 公共 Verdict 发布、`coverage.temporal` 接线、`mechanic.ts` / `api.ts` 接线（I-03）；
- Runtime、CLI、MCP、公共 Contract、持久化证据链（I-03 / 后续）；
- 任何新第三方依赖。

**模型条件性**：I-02 的所有结论都是**内部、模型条件性**结果。`coverage` 保持 `partial`；`publicCapability` 恒为 `BLOCKED`；`publicResult` 恒为 `null`。内部 `nb-candidate` / `pu-candidate` 不是公共 `NO_PROVEN_BLOCKER` / `PROVEN_UNPLAYABLE`。

## 3. 冻结语义

### 3.1 三角波运动模型（D2）

```text
u(t) = (((t mod P) + P) mod P) / P
p(t) = at + d · k(u)
k(u) = 2u          (u < 1/2)
     = 2 − 2u      (u ≥ 1/2)

v_max = 2 · d / P        [px/ms]
```

- `t = 0` 时锚点在 `at`；`P = periodMs` 是**往返整周期**；折返点在 `t = k·P/2`；两端不停留。
- `p(t)` 是 Hazard **锚点**位置，不是碰撞盒左上角。
- 时间只用 game-time（ms），允许负时间与多周期；`p(−t) = p(t)`。
- 速度只在**开区间**上定义为 `+v_max`（上升段）或 `−v_max`（下降段）；折返点导数不存在，**不定义全局速度函数**。
- 折返点必须作为连续求交的**切段边界**；任何单段求交不得跨过折返点。
- **速度是派生量，不是输入**：不新增 `Motion` 字段。I-02 需求 §4 把速度列为输入属于需求误述（D2 §2）。

### 3.2 AABB、epsilon 与几何来源（D2、D8、I02-06）

**碰撞谓词**固定为 `overlapsStrict`：

```text
a.x < b.x + b.w ∧ b.x < a.x + a.w ∧ a.y < b.y + b.h ∧ b.y < a.y + a.h
```

- 相切、角接触、零面积接触**不算撞**；任意正面积严格重叠算撞。
- Phaser 3.90.0 矩形 AABB 使用严格不等号（`World.js:1698-1713`），`overlap` / `collide` 共用同一谓词；I02-06 已证 **strict 未被推翻**。该证据只证谓词语义，不证 Runtime hitbox equality。

**epsilon**：

```text
ε = max(1e-9, 1e-9 × (xMax − xMin))
```

- ε 是**单一具名常量**，只用于门宽判定与显式区间阈值；
- **ε 不进入碰撞谓词**；不得用 ε 收缩或扩张 AABB 来“避开相切”；
- 任意小的正安全窗口必须保留；不得用 `hi − lo > 1e-9` 吞掉。

**几何来源**：

- Hazard 盒 = manifest `asset.size` + `asset.anchor`；**忽略 `entity.body`**；
- 玩家盒 = manifest `size` + `anchor`，经 `footOf` / `boxFromFoot` 派生；**不取整**；
- I-01 `TrustedAtlasInput` 是信任门禁，不是几何来源；`rotated` / `trimmed` ⇒ IE；
- 连续核心不取整；空间层 `entityBox` 的取整差 ≤0.5px/边，由 D4 的保守包络吸收；
- 连续求交应在局部坐标帧内计算，避免 `|x| ~ 1e9` 时 `1e-9` 重叠不可表示（I02-03 F7）。

### 3.3 时间、相位与 lag（D1、D2、D5）

- 初始相位 `φ0` 在出生时未知；量化 = **universal-per-phase**：`∀φ0 ∈ Φ0`。
- 每个 `φ0` 允许自己的策略；策略可以依赖精确相位。
- `T_arr` **不是入参**；它由策略轨迹派生，且必须是可计算、可验证的时间量。
- Witness 方向碰撞使用 `hazardSpeed × lagMs` 的保守扫掠带（`lagPad`）；
- PU 门区方向**不使用 pad**；`⋂δ` 在 `∀φ0` 下由全周期交集自动满足。
- 两档 lag（`16.67ms` / `200ms`）必须**分别完整分析**；不允许跨档共享或拼接 Witness / 证明。
- `NB ⇔ U9 ∨ (∀φ0 : (spawn, φ0) ∈ W)`；U9 与 W 是两条独立充分证书。
- PU 由 I-00 六条件独立判定；**无 witness 永不参与 PU**。

**模型外**（`applicable:true` + IE）：

| 输入 | 结果 |
| --- | --- |
| 没有移动 Hazard | `applicable:false` |
| Y 轴移动 | IE |
| 多于一个移动 Hazard | IE |
| Moving Platform | IE |
| Danger 联合 | IE |
| 非 `cycle` / 状态转换 | IE |
| Hazard 资源缺失或几何不可解 | IE |

### 3.4 连续时间求交（I02-03、D8 R1）

- 在折返点处切段；每段内 `p(t)` 线性，斜率由中点所在单调段给出（`±v_max`）。
- 每段解两个线性不等式，得到**开区间**；`hi > lo` 才算碰撞区间；相邻区间按 S4 合并。
- `c1 === 0` 是**精确分支**；不得用速度差容差把极小但非零的速度差归零。
- 折返点切点、负时间、多周期、同速 / 近速、`dt = 0`、非有限值均须覆盖。
- **不得以固定帧采样或粗粒度采样替代连续判定**；采样只可用于测试对照，不可用于结论。
- 在 D10 的相位网格下 `dt = P/N ≤ P/2`（`N ≥ 2`），一次 check 最多跨一个内部折返点：
  - `cutPoints ≤ 1`，`segments = cutPoints + 1 ≤ 2`（D5B 实测 99.94% 为 0）。
- `maxCutsPerCheck = 1,000,000` 是单次 check 的 DoS 守卫。

### 3.5 状态空间、Witness 与到达（D3、D10）

**状态与网格**：

```text
xStep    = 1
N_max    = floor(maxSpeed · periodMs / xStep)
N        = min(N_max, floor(maxStates / xPositions))
N        ≥ 2
dt       = periodMs / N
maxStep  = maxSpeed · dt
```

- 状态 `(footX, k)`，`footX` 锚在脚点整数格；`k` 是相位格索引。
- 合法范围按玩家盒左上角：`x_left ∈ [0, W − pw]`、`y_top ∈ [0, H − ph]`。
- 走廊收窄为 spawn 脚点 y 上的 `standable` 连通段；`standable` 只看 `blocked`，Hazard 只进 `forbidden`。
- `config.player.at` 按**脚点**解释；spawn 必须真实落在整数格，否则 IE `spawn-not-on-lattice`；**禁止** `round()` 吸附与 `startCells()` 宽松起点。
- Goal Rect 采用空间层取整盒；到达谓词 = 未取整玩家盒与**四边内缩 0.5px** 的取整 Goal Rect 严格相交。

**段原语与验证**：只有 `wait` / `move`（同脚点 y 的水平移动）。

| 检查 | 义务 |
| --- | --- |
| S1 | `move` 必须做静态连续 `graph.solids` 检查，不能只查端点 `standable` |
| S2 | 每段做 Hazard 折返点切段 + `lagPad` 的连续时间碰撞检查 |
| S3 | 相位与时间区间必须连续、可达 |
| S4 | 相邻区间碰撞结果按切点合并；连接处位置 / 时间 / 状态连续 |

- 残差等待必须对整个相位格内的 Hazard 位姿范围做**保守验证**；不得只查格端点。
- U9 的整周期等待使用整格保守覆盖，不得写成“全部具体 `φ0` 轨迹均已验证”。

**U9（Safe Waiting Cell）**：

1. `s` 是 `graph.standable` 的玩家脚点格；
2. 对每个 `φ0`，存在从 `(spawn, φ0)` 到 `s` 的无碰撞路径；
3. 在 `s` 停留完整周期 `P`，对每个 `φ0` 整个等待期间无碰撞；
4. 路径与等待都使用 Witness 的 `lagPad`；
5. 任一不可验证 ⇒ U9 不成立。

**全相位 Winning Set（W）**：

- `W` 是 1D 走廊 × 相位格上的**最小**不动点 `μX.(Goal ∪ Pre∃(X))`；
- 必须覆盖全部 N 个半开相位格 + 残差等待；不能只用 phase 0 或有限采样；
- 策略必须带严格递减 rank 或有限轨迹；
- `W` 成立 ⇒ NB 候选；U9 / W 任一完整成立即可；两者均失败仍只能 IE，不得推 PU。

**Witness 形状**（D9）：

- 正式 Witness = **策略表 + 逐转移验证记录 + 终止性证明**；路径族是派生视图；
- 每条转移紧凑记录：`[fromFoot, fromK, toFoot, toK, t0, t1, verified]`；
- 玩家盒与 Hazard 位姿由 `(footX, k, t)` + 冻结公式**确定性派生**，标 `derived: true`；
- 必须测试派生盒与解析求交使用的几何完全一致；
- 序列化必须确定性；体积以最终 UTF-8 字节数为准；
- `maxWitnessTransitions = 1,000,000`、`maxWitnessBytes = 64 MiB`；任一超限 ⇒ IE `witness-volume`。

### 3.6 永久封锁门（D4）

```text
p(θ) = at + d·k(θ/P)，θ ∈ [0, P)
gateRect = [L, R] × [hazY, hazY + hazH]

L = at + d − anchorX · w
R = at + (1 − anchorX) · w
门宽 = R − L = w − d
```

- 门区 = Hazard **全周期恒覆盖**的 x 核心；宽度必须 `w − d > ε`；
- 对 `∀φ0` 取交集；门区**不加 Witness 的 lag pad**；
- `gateRect` 原样注入 `buildMovementGraph({ forbiddenBoxes: [gateRect] })`；扩张只由 `graph.ts` 做一次，不得预扩张、不得写入 `blocked`；
- `forbiddenBoxes` 语义：不可穿越、不提供支撑、门顶不是地板；
- 判侧：

```text
goalRegion = inflate(goalRect, 0.5)

左→右：spawnBox.x + spawnBox.w ≤ L ∧ goalRegion.x ≥ R
右→左：spawnBox.x ≥ R                 ∧ goalRegion.x + goalRegion.w ≤ L
```

- 记录 `forbiddenInjection: { gateRect, expandedRect, source: "forbiddenBoxes" }`；
- 门区与图割必须使用同一份静态 solids、玩家几何与 profile。

### 3.7 垂直规避图割与 hop 加倍（D4）

图割判据（仅条件性证据）：

1. 没有任何可达落脚点的玩家盒与 `goalRegion` 严格相交；
2. 没有任何可达 hop 弧采样点的玩家盒与 `goalRegion` 严格相交。

- 使用 `assessReachability(graph, move, [{ rect: goalRegion }], { full: true })` 并检查 `covered` / `midAir`；
- **`midAirHits = 0` 不是不可达证明**：它只能作为否决条件（命中 ⇒ 不得 PU），永远不能作为支持 PU 的正面证据；
- `graphCut.verdict` 只能是 `"conditional"`；
- hop 双档（60 / 120Hz）分别记录 `n` / 端点 / cap，并验证倍档规范化采样位置覆盖主档；**不要求 `n` 精确 2×**；
- 采样加密后若推翻原不可玩证明，原证明必须失效并降级；
- `movementModelClosure = "not-proven-air-control"`（`scene.ts:89` 空中水平控制未闭合）；
- 生产 PU **不授权**：PU 六条件第 2 条（几何 `checked`）与第 5 条（模型外规避排除）为 `BLOCKED`；第 6 条（双档 lag 一致）为构造性 lag 无关。

### 3.8 判定语义与内部状态（D1、D4、D8、D9）

**NB**：

- `U9` 或 `∀φ0 W` 任一完整成立 ⇒ 内部 `nb-candidate`；
- 内部 `nb-candidate` ≠ 公共 `NO_PROVEN_BLOCKER`；
- 必须携带 `coverage.temporal = checked` 才可能在 I-03 被提升（I-02 不接线）。

**PU**：I-00 六条件同时成立才可能；I-02 只做模型内计算：

| 条件 | I-02 状态 |
| --- | --- |
| 1. 门区恒覆盖 | 可计算 |
| 2. 几何 `checked` | **BLOCKED**（`coverage` 恒 `partial`） |
| 3. 图割不连通 | 条件性可计算 |
| 4. hop 加倍不变 | 条件性可计算（需 `graph.ts` 独立审批） |
| 5. 模型外规避排除 | **BLOCKED**（移动模型未闭合） |
| 6. 双档 lag 一致 | 构造性 lag 无关 |

- `pu-candidate` 只表示模型内门区 + 图割 + hop 证明完整；`geometry-checked` / `model-out-excluded` 仍 `BLOCKED`；
- 公共 `PUBLIC_PU` 在 I-03 前 `BLOCKED`；任何假 PU 是**严重证明健全性失败**。

**IE**：其余全部，不得被提升；包括预算耗尽、搜索无解、采样未撞、模型外、几何不可信、双档不一致或至少一档不完整。

**内部状态词汇**（D9）：

- `internalResult`: `"nb-candidate" | "pu-candidate" | "insufficient-evidence"`；
- `modelConditional: true`；
- `publicCapability: "BLOCKED"`；

## 4. 预算、确定性与降级

### 4.1 预算终值（D5、D5B）

| 预算 | 默认 | 硬上限 | 作用域 / 计量 |
| --- | ---: | ---: | --- |
| `maxStates` | 500,000 | 1,000,000 | U2 NB / 每档 lag；U9 + W 共用 |
| `maxEdges` | 派生 `maxStates × maxBranching` | 派生 | U2；须防溢出 |
| `timeBudgetMs` | 2,000 | 10,000 | 每分支 / 每档 lag；**abort-only** |
| `maxCutsPerCheck` | 1,000,000 | 1,000,000 | U1 单次连续求交；**cutPoints** |
| `maxCutsPerBranch` | **5,000,000** | **10,000,000** | U2 每档 lag 累计；**segments = cutPoints + 1** |
| `maxWitnessTransitions` | 1,000,000 | 1,000,000 | U2 Witness 体积 |
| `maxWitnessBytes` | 64 MiB | 64 MiB | U2 Witness 体积；实际 UTF-8 字节 |
| `maxHopSamples` | 240 / arc | 240 / arc | U4 双档采样 |
| `timeBudgetCheckpointWork` | 1024 work units | 1024 | 墙钟检查粒度 |

- **工作预算是唯一语义预算**；墙钟只 abort-only，不计入确定性签名。
- 累计 cut 预算不得先于状态 / edge 预算触发，否则降级原因会从 `state-budget` / `edge-budget` 变成 `cut-budget`。
- U2 与 U4 预算独立；两档 lag 预算独立；U9 与 W 共用 NB 预算。
- 测试只能通过内部注入钩子使用受控预算；生产不得按关卡设置预算。
- 本包**采用 segments 语义**（`cutPoints + 1`），因此 `maxCutsPerBranch = 5,000,000 / 10,000,000` 生效。cutPoints 读数的 fallback（`1,000,000 / 4,000,000`）仅作为历史备选记录，**不在本包生效**；若未来改用 cutPoints，必须重新走 AUTH 修订。

### 4.2 相位网格与非法预算

```text
N_max        = floor(maxSpeed · periodMs / xStep)
N            = min(N_max, floor(maxStates / xPositions))
stateCapacity = xPositions · N
```

- `N ≥ 2`，否则 IE `grid-resolution-infeasible`；
- `stateCapacity` 是**理论状态空间上界**，不是实际访问量；
- `phaseGridCapped` 是诊断，不是降级 Verdict；粗化必须配合整格残差验证；
- 非有限、`timeBudgetMs ≤ 0`、`maxStates < 1`、派生上界溢出 ⇒ IE `invalid-budget` / `budget-bound-overflow`；不得回退默认值继续。

### 4.3 确定性与降级

- 相同输入、相同配置必须产生确定性结果；所有策略遍历顺序固定；`wallClockMs` 不进 `determinismSignature`。
- `determinismSignature` = 纯 JS FNV-1a 32-bit 十六进制串，覆盖 grid / work 计数 / `internalResult` / certificate / diagnostics 原因码 / budget 状态；排除 `wallClockMs`、`detail`、时间戳、test hooks。
- **32-bit 签名只是指纹**；测试必须同时比较剔除 `wallClockMs` / `detail` 后的规范化完整序列化。
- 降级原因码使用 D9 §5 的**闭集**；双档「至少一档不完整」与「两档完整但不一致」必须分开：后者 `lag-disagreement`，前者保留实际预算 / abort 原因。
- 超限：逐层降级为 IE；不允许部分 witness / proof；预算耗尽是单向 `SAFE → IE`。
- 不得静默扩预算、失败后自动重试、切换算法绕过硬上限。

### 6.2 Witness（W1）

```ts
type WitnessTransition = readonly [
  fromFoot: number, fromK: number, toFoot: number, toK: number,
  t0: number, t1: number, verified: 0 | 1,
];

type Witness = {
  readonly form: "u9" | "winning-set";
  readonly derived: true;
  readonly verifications: readonly WitnessTransition[];
  readonly policy: readonly number[];            // verifications 下标
  readonly termination:
    | { readonly kind: "rank"; readonly rank: readonly number[] }
    | { readonly kind: "trace"; readonly finite: true; readonly length: number };
  readonly phaseCoverage: { readonly cells: number; readonly covered: number; readonly complete: boolean };
  readonly volume: { readonly transitions: number; readonly bytes: number };
};
```

- 盒由 `(footX, k, t)` + 冻结公式确定性派生；`derived: true` 不是推测。
- 必须有「派生盒 == 解析盒」测试。
- `volume.bytes` 是最终确定性序列化 UTF-8 字节数；超 `1M` 或 `64 MiB` ⇒ IE `witness-volume`。

### 6.3 Proof

`PermanentGateProof` 保留 D4 字段：`gate / periodCoverage / sideRule / forbiddenInjection / graphCut / hopDoubling / hopSamplingCoverage / movementModelClosure / puConditions / geometryCoverage / lagMode / lagInvariantByConstruction`。

- `graphCut.verdict = "conditional"`；`midAirHits` 只作否决；
- `movementModelClosure = "not-proven-air-control"`；
- `puConditions` 六条齐全，`PASS` 必有 `evidence`，`BLOCKED` 必有 `blockedReason`；
- `geometry-checked` / `model-out-excluded` 必须 `BLOCKED`；
- `certificate.status = "COMPLETE"` 只表示模型内证明完整，不表示 PU 六条件全部 PASS。

### 8.3 数值与边界

| 类别 | 必须覆盖 | 预期口径 |
| --- | --- | --- |
| AABB | 严格重叠 / 相切 / 零面积接触 | strict：相切、角接触、零面积不算撞；正面积算撞 |
| ε | 门宽判定两侧、区间阈值两侧 | ε 只用于门宽 / 显式区间阈值，不进碰撞谓词 |
| 方向 | 正向 / 反向 / 折返点切段 | 折返点不定义速度；单段不得跨折返点 |
| 周期 | `t=0`、`P/2`、`P`、负时间、多周期 | `p(−t)=p(t)`；周期起终点一致 |
| 速度 | 同速 / 近速 | `c1 === 0` 精确分支；不得用绝对容差归零 |
| 窗口 | 极短安全窗口（如 `1.005e-6 ms`） | 必须保留；不得被 `hi−lo>1e-9` 吞掉 |

| 非法值 | 无效周期、非有限数值 | IE；不得静默修复 |
