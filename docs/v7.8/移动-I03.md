### 3.3 `coverage.temporal` 取值

| 值 | 条件 |
| --- | --- |
| `checked` | 输入 brand 有效、模型适用、两档都完成（`budgetStatus="complete"`），且无 `model-out` / `invalid-input` / `geometry-untrusted` |
| `partial` | 分析已开始、输入 / 模型检查通过，但一档或两档因预算 / 墙钟 / Witness 体积不完整 |
| `unknown` | 不适用、`model-out`、非法输入、`geometry-untrusted`，或没有可消费的时序分析结果 |

- 时序 evidence 必须设置 `coverage.temporal`；非时序 evidence 可缺省。
- `coverage.spatial / mechanic / completion` 从 `auditPlayability` 原样复制；取不到时用 `not-checked`，不得伪造 `checked`。
- `coverage.temporal = checked` **不**推出公共 NB；几何 gate 与证据准入是独立条件。

### 3.4 `lag` 与 `limits`

- `lag.perLag` 恰好两项，顺序固定 `[主档 input.lagMs, 基准档 secondLagMs]`。
- `perLag[i]` 只含结论摘要；不含逐档 Witness / proof / stats。
- 两档不一致时保留两档结论；主 evidence 取合并结果（`insufficient-evidence` + `lag-disagreement`）。
- `limits` 从内部 `stats.budget` / `stats.work` / `budgetProfile` 取值；`hopSamplesChecked` 目前恒为 0（U5 已知缺口），不得伪造为 `maxHopSamples` 或非零值。
- `limits.geometryCoverage` 固定摘要 `"partial"`；三份明细在 `model.geometryCoverage`。

- `judgmentId`：**`PLAYABILITY_TEMPORAL_EVIDENCE`**（单一稳定 id；结论在 `witness.result`）。

### 3.6 不变量

## 4. 公共 Verdict 与 coverage 语义（I03-02）

### 4.1 能力门（内部输入，不是公共字段）

```ts
/** @internal 只由 I-03 准入机制设置；第一阶段两项都 BLOCKED。 */
export type PublicCapabilityGate = {
  readonly nb: "BLOCKED" | "OPEN";
  readonly pu: "BLOCKED" | "OPEN";
};
```

- 第一阶段：`{ nb: "BLOCKED", pu: "BLOCKED" }` 硬编码；不按关卡配置，不进入 `GameConfig` / profile / 公共 API。
- gate 状态**不从 evidence 推断**；`coverage.temporal="checked"` 或 `certificate COMPLETE` 都不能把 gate 当成 `OPEN`。
- `gate = OPEN` 只由 §8 / §9 的准入链设置。

| --- | --- |
| `existing = PROVEN_UNPLAYABLE` | `PROVEN_UNPLAYABLE`（不被 temporal 削弱） |
| `existing = INSUFFICIENT_EVIDENCE` | `INSUFFICIENT_EVIDENCE`（优先于 temporal） |
| 无移动 Hazard（`temporal` 不适用） | `existing`（`coverage.temporal` 缺省） |
| 有移动 Hazard，`coverage.temporal` 缺失 | 按 `unknown` ⇒ IE |
| 有移动 Hazard，`temporal = partial / unknown` | IE |
| 有移动 Hazard，`checked` + 内部 IE | IE |
| 有移动 Hazard，`checked` + `nb-candidate`，`gate.nb = BLOCKED` | IE |
| 有移动 Hazard，`checked` + `nb-candidate`，`gate.nb = OPEN` 且证据准入通过 | `NO_PROVEN_BLOCKER` |
| 有移动 Hazard，`checked` + `pu-candidate`，`gate.pu = BLOCKED` | IE |
| 有移动 Hazard，`checked` + `pu-candidate`，`gate.pu = OPEN` 且证据准入通过 | `PROVEN_UNPLAYABLE` |

> **`gate = OPEN` 不是发布充分条件。** 证据准入仍必须通过；gate OPEN 但准入未通过 ⇒ IE。

### 4.3 优先级

```text
existing PROVEN_UNPLAYABLE
  > existing INSUFFICIENT_EVIDENCE
  > temporal 适用导致的 IE
  > NO_PROVEN_BLOCKER
```

- temporal **不能**把现有 `PROVEN_UNPLAYABLE` 改成更弱结论。
- temporal **不能**把现有 `INSUFFICIENT_EVIDENCE` 改成 `NO_PROVEN_BLOCKER`。
- temporal 只有在 `existing = NO_PROVEN_BLOCKER` 时才可能产生 `NO_PROVEN_BLOCKER` / `PROVEN_UNPLAYABLE`（后者需 `gate.pu = OPEN`）。
- **冲突规则**：`existing = PROVEN_UNPLAYABLE` 且 temporal 给出 candidate 且对应 gate `OPEN` ⇒ **STOP + HITL**；不得静默择一。第一阶段 gate 全 `BLOCKED`，不触发。

### 4.4 `coverage.temporal` 聚合

- 适用性由 `temporalScope(config).applicable` 决定；字段缺省表示“不适用”，不参与 verdict。
- 适用时适配器必须设置字段；缺失按 `unknown` ⇒ 在 `existing = NO_PROVEN_BLOCKER` 时拉成 IE。
- `checked` 只表示输入 / 模型检查完成；**不**表示 geometry `checked`，也**不**表示公共 NB / PU 准入。
- `partial` / `unknown` 一律不得聚合为 `NO_PROVEN_BLOCKER`。
- `coverage.spatial / mechanic / completion` 的既有行为不变；temporal / geometry 是加法字段。

### 4.5 `moving-hazard-phase` gap 的替换（实施边界）

- `auditMechanic` 不再因“存在移动 Hazard”而加 `moving-hazard-phase` gap；
- 移动 Hazard 的不确定性由 temporal 层的 `coverage.temporal` + evidence 承载；
- `coverage.mechanic` 不再因该 gap 被置 `partial`；其余静止 Hazard / frame 几何导致的 `partial` 保持不变；
- 聚合按 §4.2 / §4.3 处理；第一阶段 gate `BLOCKED` ⇒ 含移动 Hazard 的关卡仍是 IE，拒稿行为不变；
- `mechanic.ts` / `api.ts` 的修改必须逐文件列入 I03-07 白名单；受影响的既有测试必须按新语义改写并保留负向覆盖，**不得删除或放宽**既有安全断言。

### 4.6 `playabilityIssues` 与非阻断

- `PLAYABILITY_TEMPORAL_EVIDENCE` 第一阶段非阻断：不产 `ConfigIssue`，不进入 `publish-gate` 拒稿。
- `playabilityIssues` 的既有映射不变：只有 `PROVEN_UNPLAYABLE` 的阻断型 evidence 产 error；temporal 候选名不是公共 Verdict，不产 issue。
- 未来 `PUBLIC_PU` 准入若需要阻断型 temporal ID，必须另开 gate 变更审查。

## 6. 几何 / Runtime hitbox 证据 gate（I03-03）

### 6.1 公共 `coverage.geometry` 汇总

```ts
export type CoverageState = "checked" | "partial" | "not-checked";
export type PlayabilityCoverage = {
  readonly spatial: CoverageState;
  readonly mechanic: CoverageState;
  readonly completion: CoverageState;
  readonly temporal?: TemporalCoverageState;
  readonly geometry?: CoverageState;
};
```

- 三份分项全部 `checked` ⇒ `geometry = "checked"`；
- 三份全部 `not-checked` ⇒ `geometry = "not-checked"`；
- 其余组合 ⇒ `geometry = "partial"`；
- 汇总值**不能**替代 NB / PU 各自的分项准入判断。

### 6.2 `checked` 的两层证据（缺一不可）

1. **构建期 Atlas 证据**：Atlas JSON / PNG 的逐帧 `sourceSize`、`anchor`、`trimmed`、`rotated` 与 manifest 一致；使用与 `files[]` 同一份字节 + SHA-256；TOCTOU 规则照 I-00 §3.1；缺帧 / anchor 缺失 / 哈希不符 / rotated / trimmed ⇒ 该分项不得 `checked`。
2. **运行时 Phaser probe**：读取实际 frame / body bounds、anchor、offset；在固定夹具上逐项比较 `runtimeEntityGeometry` / `runtimePlayerGeometry` 的 box / size / anchor / foot；probe 未运行、证据不完整或无法比较 ⇒ 不得推断 `checked`。

`verifyTemporalInput` 只支持 Atlas **元数据**可信，**不足以**证明 Runtime 碰撞几何一致。

### 6.3 按能力的几何准入粒度

| 能力 | 必需几何分项 |
| --- | --- |
| NB witness | `hazard` + `player` |
| NB 中涉及图割的证明 | 额外要求 `graph` |
| PU | `hazard` + `player` + `graph` 全部 `checked`，并满足 I-00 六条件 |

### 6.4 证据不足 / probe 失败的降级

- 任一分项 `partial` ⇒ 汇总 `partial`；对应准入不通过；公共 Verdict 保持 IE。
- **仅仅缺少证据**不新增 `geometry-partial` degradation。
- probe 发现实际几何与模型不一致 / 输入不可信 ⇒ `geometry-untrusted`，保持 IE。
- `partial` 是覆盖状态；`geometry-untrusted` 是有负面证据支持的降级原因。

### 6.5 probe 证据契约（I03-03A）

- 一次运行一个 JSON，逐帧 / 逐 body 记录 `expected / actual / delta / pass`；summary 只作索引。
- 零容差 + 显式坐标归一化；任何非零 delta ⇒ 分项不得 `checked`；坐标约定不明确 ⇒ STOP。
- Atlas JSON / PNG + 规范化结果 SHA-256；环境 / 时间戳只作 metadata。
- 失败码闭集：`atlas-missing` / `atlas-hash-mismatch` / `frame-missing` / `frame-size-mismatch` / `anchor-mismatch` / `trimmed` / `rotated` / `body-size-mismatch` / `body-offset-mismatch` / `body-bounds-mismatch` / `graph-solid-mismatch` / `probe-not-run` / `environment-mismatch` / `nondeterministic`。
- 失败类别：`missing-evidence` ⇒ partial；`geometry-mismatch` ⇒ untrusted + `geometry-untrusted`；`environment` ⇒ partial，禁止跨环境比较；`nondeterministic` ⇒ partial。
- probe 是证据生成器，不是 CI：`all-checked` / `partial` / `untrusted` 都退 0；仅 harness 崩溃 / 无证据退非 0。

### 6.6 固定夹具矩阵（I03-03B / I03-03B2）

- 基底：`fixtures/packs/last-train/v2`（只读）；scratch 归一化副本 `last-train-v4`；原始 fixture 不被 probe 修改。
- 源 pack tree hash：`sha256:570535deff5c2f4e1626b2680a4b555f631e51d6d87721507a0a1f6e2feb7383`。
- 源 manifest hash：`sha256:145cb28d73e5723a458c2cffc7f3b362fa3009f8647ac879dad1ec819ffbd689`。
- 归一化 manifest hash：`sha256:19f4da6fb9bf25b96b48b96e2e44bb1773ad0c1222dc865f72e77a56fc85cb98`。
- **正例行 14**：hazard 2 / player 8 帧 + player body 1 / graph 3。
- **负例 10**：7 个 geometry-mismatch（player / hazard / graph 按 affected）+ `atlas-missing` + body-size / body-offset / graph-solid override。
- 每个负例只改变一个主要变量；`environment-mismatch` / `nondeterministic` 只作 review-only；`probe-not-run` 不造夹具。
- 正例清单先冻结；probe 实现后不得删减失败对象；同一基底 + 同一变异 ⇒ 相同语义内容与 hash。
- 变异副本必须能从冻结基底 + 记录变换确定性重建；不得手工编辑最终证据后宣称通过。

### 6.7 玩家坐标约定（I03-03B2a）

- `config.player.at` = **锚点落点**（draw anchor），不是脚点。
- `foot = footOf(at, size, anchor)`；`playerBox = boxFromFoot(foot, size)`，**不取整**。
- last-train 实例：`at=(40,250)`、size `32×48`、anchor `.95` ⇒ `foot=(40,252.4)`、`playerBox=(24,204.4,32,48)`。
- **D2 冲突处理**：`footOf` / `boxFromFoot` 为规范；“`player.at` 按脚点解释”在 I-03 范围内被本裁定取代。不修改 D2 / I-02 原文。
- demo `world.player.box`（取整）是**绘制盒**，不是 body / audit 期望；probe 必须分别记录 sprite bounds 与 body world AABB。
- 实施修正：`resolveWitnessSpace` 不再把 `player.at` 直接当脚点；`temporal-witness.ts` 必须逐文件列入 I03-07 白名单。
- 整数格与分数脚点：状态格仍以整数 `at` 为 lattice anchor；玩家盒用 `foot` 的**常量偏移**派生；不得截断 / 取整 foot，也不得把分数 foot 直接塞进 `spawn.footX/footY`；无法表达 ⇒ STOP + HITL。
- 零容差：audit player box 不取整；Phaser body world AABB 与它零容差；body size / offset / bounds / foot 逐项记录；`delta` 只作诊断。

### 6.8 独立复核（I03-03C）

- **fresh 独立会话**，未参与 probe、证据格式、夹具或 manifest 编写。
- 只接收 probe 契约、逐行 manifest、原始 JSON / hash / 命令 / 冻结基底、覆盖与负例设计；必须自己重建 / 重跑 / 检查。
- 逐项检查 12 项：夹具完整性、hash 可重建性、每行 `expected/actual/delta/pass`、零容差与坐标归一化、失败码 class 映射、summary 聚合、runner / environment、同环境重跑、负例单变量隔离、无虚假 `checked`、原始证据未被手工修改、至少 2 条自选关键断言。
- hazard / player / graph 各自独立 `PASS / FAIL / NOT_RUN`；只有该分项全部 required rows + 清单项 PASS，才能写 `evidence supports checked`。
- 不允许整体通过率推导分项通过；不允许 hazard 通过推广到 player / graph。
- 环境不匹配 ⇒ 分项保持 `partial` + `environment-mismatch`，不得判 `geometry-mismatch` / `geometry-untrusted`。
- 确定性失败 ⇒ `nondeterministic` + `partial`，不得判 checked。
- 报告路径：`.scratch/level-playability-v1.1-i03/reports/geometry-probe-review.md`。
- 复核 PASS 只表示“证据足以支持被复核的几何分项”；**不**自动设置 `coverage.geometry`、**不**通过 NB / PU 准入、**不**开放能力。

- `ADMITTED → OPEN`：独立复核 + 用户显式授权 + gate `BLOCKED → OPEN`。
- `OPEN → BLOCKED`：确认假 NB（§8.6）。
- `PUBLIC_PU` 不因 NB 阶段推进获得任何隐含授权。

### 8.2 阶段 2 准入条件（全部同时满足）

| 条件 | 准入要求 |
| --- | --- |
| 几何 | `hazard + player` checked；涉及图割时 `graph` 也必须 checked |
| 几何复核 | I03-03A/B/C 三层独立复核通过 |
| 时序覆盖 | `coverage.temporal = "checked"` |
| 双档 lag | 两档均完整且结果一致 |
| Certificate | `kind = "witness"`、`status = "COMPLETE"` |
| 预算 | 无预算耗尽、无 wall-clock abort |
| 确定性 | 满足冻结的跨进程确定性要求（签名 + 规范化序列化） |
| 体积 | Witness 未触发 transition / bytes 上限 |
| 公共映射 | 符合 §3 的 evidence / Verdict 映射 |
| Admission fixtures | 固定夹具集全部通过 |

固定 admission 夹具集必须包含：

1. **Synthetic NB 正例**：合法 NB 通过完整准入。
2. **False-NB 负例**：不满足全相位安全条件的候选**不会**错误通过。
3. **真实 IE 负例**：模型外 / 证据不足 / 预算异常仍保持 IE。

- 19 关历史语料只作 **IE 不回归**证据，不能替代 NB 正例。
- 夹具集必须在运行正式 admission 测试前冻结并记录 hash；禁止根据测试结果调整样本。
- 阶段 2 通过只表示证据准入条件成立，**不自动改变全局能力状态**。

### 8.3 阶段 3 开放

必须同时满足：

- 独立复核通过（复核人未参与实现 / probe / 夹具）；
- 用户显式授权；
- `PUBLIC_NB` gate 从 `BLOCKED` 明确变更为 `OPEN`。

开放后，每个关卡仍须独立通过 §8.2 证据准入，才能得到公共 `NO_PROVEN_BLOCKER`。

### 8.4 能力粒度

- `PUBLIC_NB` 是**全局能力**；不建立逐关 allowlist。
- gate `OPEN` 后，任何满足 §8.2 条件的关卡可产生公共 NB；不满足的仍为 IE。
- 不增加按关卡预算或开关；关卡差异由实际证据决定。

### 8.6 假 NB 回滚与证据失效

1. 全局 `PUBLIC_NB` gate **立即关闭**。
2. 受影响关卡公共结果退回 `INSUFFICIENT_EVIDENCE`。
3. 受影响证据标记失效，不得继续作为准入依据。
4. 重新开放必须重新完成根因分析、修复、独立复核与显式授权。
5. 不能只回滚单个关卡而让全局能力继续开放；不能静默保留旧证据。

证据基线元组：

| 轴 | 内容 |
| --- | --- |
| `algorithmVersion` | I-02 U5 提交 / 内部算法版本 + I-03 adapter 版本 |
| `geometryBaseline` | profile id、`graph.ts` 版本、atlas JSON / PNG hash、probe 契约 / 夹具 manifest hash |
| `proofRulesVersion` | D9 / D10 / I-00 六条件 / I03-03 gate 规则版本 |
| `fixtureVersion` | admission / probe 夹具版本与 hash |

- 假 NB 确认后，所有依赖同一失效基线元组的结果全部失效。
- 失效后必须重新建立基线、重新独立复核、重新授权；不得用旧 hash 继续。
- 若失效只因某个夹具 / 关卡输入，仍需证明其他关卡不依赖该失效输入；不能默认豁免。

**关闭优先级**（高于缓存 / 历史产物 / 逐关准入 / “曾通过”）：

- 公共读取路径必须先检查 gate；`BLOCKED` ⇒ 一律 IE / 不返回 NB。
- 缓存键必须包含 gate 状态 + 证据基线元组；gate 关闭后旧缓存不得命中。
- 不允许“gate 已关闭但缓存 / 历史产物仍返回 `NO_PROVEN_BLOCKER`”。

## 9. `PUBLIC_PU` 独立准入链（I03-05）

### 9.1 状态机

| 阶段 | 名称 | 公共 gate | 公共结果 | 进入条件 |
| --- | --- | --- | --- | --- |
| 1 | **WIRED** | `BLOCKED` | IE | 生产链路能消费内部 PU candidate；候选只作非结论证据 |

| 3 | **OPEN** | `OPEN` | 逐关通过六条件后 `PROVEN_UNPLAYABLE` | 独立复核 + 用户显式授权 + gate 变更 |

- 三阶段独立记录；内部 candidate 出现不等于能力开放。

### 9.2 六条件 gate

| # | 条件 | 当前约束 | 状态语义 |
| --- | --- | --- | --- |
| 1 | 永久门区证明 | 必须完整 PASS | 全周期闭式覆盖 + 判侧 + forbidden 注入完整 |

type PUConditionStatus = "PASS" | "BLOCKED" | "INSUFFICIENT_EVIDENCE" | "NOT_RUN";

- 不使用总分、加权、通过率或多数决。
- `ADMITTED` 仍不等于 `OPEN`。
- **当前条件 2 和条件 5 硬阻断**；即使 1/3/4/6 通过，也不能开放 `PUBLIC_PU`。

### 9.3 条件 5 独立闭合票

3. 证据产生者与产生方式。
4. 负向测试矩阵。
5. 独立复核人与复核标准。
6. `PASS / FAIL / INSUFFICIENT_EVIDENCE` 判定规则。

未闭合前：

- PU 条件 5 恒 `BLOCKED`；
- `PUBLIC_PU` 恒 `BLOCKED`；
- U4 conditional graph cut 只证明模型范围内不可达，**不能**证明 Runtime 实际不可达；

- 夹具先冻结并记录 hash；禁止事后调整样本。
- 正例必须真实满足完整准入合同，不能弱化条件制造正例。

- U4 现有合成测试只作部分证据，不能替代完整 admission fixtures。

**正常关闭**：U1–U5 全部完成独立复核与用户签署；Ledger 完整；全量测试、类型检查、依赖守卫全绿；`PUBLIC_NB` / `PUBLIC_PU` 仍 `BLOCKED`；`publicResult=null`；发布拒稿行为与冻结基线一致；无未处理的白名单外修改或未解决 STOP。

**关闭 ≠ 开放**：I-03 正常关闭只表示生产接线、证据映射、诊断接管与复核工作完成；`PUBLIC_NB` / `PUBLIC_PU` 开放是独立的后续准入决策。
